## Spacing Scale

| Class | মান | পিক্সেল |
| --- | --- | --- |
| p-0 / m-0 | 0 | 0px |
| p-1 / m-1 | 0.25rem | 4px |
| p-2 / m-2 | 0.5rem | 8px |
| p-3 / m-3 | 0.75rem | 12px |
| p-4 / m-4 | 1rem | 16px |
| p-5 / m-5 | 1.25rem | 20px |
| p-6 / m-6 | 1.5rem | 24px |
| p-8 / m-8 | 2rem | 32px |
| p-10 / m-10 | 2.5rem | 40px |
| p-12 / m-12 | 3rem | 48px |

## Padding ও Margin

<CodeBlock code={"<!-- চারদিকে padding -->\n<div class=\"p-4\">padding: 16px</div>\n\n<!-- শুধু top/bottom -->\n<div class=\"py-2\">padding-top & bottom: 8px</div>\n\n<!-- শুধু left/right -->\n<div class=\"px-6\">padding-left & right: 24px</div>\n\n<!-- আলাদা আলাদা -->\n<div class=\"pt-2 pb-4 pl-6 pr-8\">Individual padding</div>\n\n<!-- Negative margin -->\n<div class=\"-mt-4\">margin-top: -16px</div>"} lang={"html"} />

## Gap (Flexbox ও Grid)

<CodeBlock code={"<div class=\"flex gap-4\">\n  <div>Item 1</div>\n  <div>Item 2</div>\n  <div>Item 3</div>\n</div>\n\n<div class=\"grid grid-cols-3 gap-6\">\n  <div>Col 1</div>\n  <div>Col 2</div>\n  <div>Col 3</div>\n</div>"} lang={"html"} />

<Tip tone={"success"} title={"mnemonic"} text={"`p` = padding (ভেতরের), `m` = margin (বাইরের), `gap` = flex/grid items-এর মাঝের ফাঁক। সংখ্যা বাড়লে জায়গা বাড়ে।"} />
