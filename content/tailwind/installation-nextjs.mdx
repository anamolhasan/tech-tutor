## নতুন Next.js Project তৈরি

<CodeBlock code={"npx create-next-app@latest my-app\n# Tailwind বাছাই করুন: Yes"} lang={"bash"} title={"Terminal"} />

<InParagraph text={"`create-next-app` interactive prompt-এ “Would you like to use Tailwind CSS?” — **Yes** বাছাই করলেই setup হয়ে যায়।"} />

## Manual Setup (যদি already project থাকে)

<CodeBlock code={"npm install tailwindcss @tailwindcss/postcss"} lang={"bash"} title={"Terminal"} />

<CodeBlock code={"const config = {\n  plugins: {\n    \"@tailwindcss/postcss\": {},\n  },\n};\nexport default config;"} lang={"javascript"} title={"postcss.config.mjs"} />

<CodeBlock code={"@import \"tailwindcss\";"} lang={"css"} title={"src/app/globals.css"} />
