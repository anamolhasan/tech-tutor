## Production Features

- **JIT Engine** — শুধু ব্যবহৃত CSS generate হয়
- **PurgeCSS** — unused CSS classes remove হয়
- **Minification** — CSS file minify হয়
- **Tree-shaking** — unused utilities বাদ যায়

## Build Command

<CodeBlock code={"# Tailwind v4\nnpx @tailwindcss/cli -i ./src/index.css -o ./dist/output.css --minify\n\n# Build script\nnpm run build"} lang={"bash"} title={"Terminal"} />

## Performance Tips

- Production-এ CDN ব্যবহার করবেন না — npm build ব্যবহার করুন
- Dynamic class names avoid করুন (template literal এ classes)
- `safelist` শুধু প্রয়োজনীয় classes-এর জন্য ব্যবহার করুন
- CSS file minify করুন

<Tip tone={"warning"} title={"Dynamic Classes এড়িয়ে চলুন"} text={"Tailwind JIT engine static string scan করে। Dynamic class construction (`text-${color}-500`) কাজ করবে না। সবসময় static full class names ব্যবহার করুন।"} />
