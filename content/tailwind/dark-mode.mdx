## Dark Mode Strategy

- **Media query** (default) — system preference অনুযায়ী
- **Class** — manual toggle (`dark` class যোগ/বাদ)

<Tip tone={"info"} title={"Dark mode toggle"} text={"JavaScript দিয়ে `document.documentElement.classList.toggle('dark')` কল করে dark mode toggle করুন। localStorage-এ save করে persistent করুন।"} />
