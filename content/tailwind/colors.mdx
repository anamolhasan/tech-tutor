## Color Intensity Scale

| Shade | বৈশিষ্ট্য |
| --- | --- |
| 50 | সবচেয়ে হালকা (lightest) |
| 100-200 | হালকা shades |
| 300-400 | মাঝারি shades |
| 500 | Default / base shade |
| 600-700 | গাঢ় shades |
| 800-900 | অতি গাঢ় |
| 950 | সবচেয়ে গাঢ় (darkest) |
