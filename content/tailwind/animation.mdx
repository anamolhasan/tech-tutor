## Transitions

<CodeBlock code={"<!-- সবকিছু transition -->\n<button class=\"bg-blue-500 text-white px-4 py-2 rounded-lg transition-all duration-300 hover:bg-blue-700 hover:scale-105\">\n  Smooth hover\n</button>\n\n<!-- শুধু specific property -->\n<div class=\"transition-colors duration-200 bg-white hover:bg-gray-100\">\n  Color transition\n</div>\n\n<!-- Transform -->\n<div class=\"transition-transform duration-200 hover:scale-110 hover:rotate-3\">\n  Transform on hover\n</div>"} lang={"html"} />

## Transition Properties

| Class | কাজ |
| --- | --- |
| transition-none | কোনো transition নেই |
| transition-all | সব property transition |
| transition | default properties |
| transition-colors | শুধু color |
| transition-opacity | শুধু opacity |
| transition-shadow | শুধু shadow |
| transition-transform | শুধু transform |
