## Learning Curve

<InParagraph text={"প্রথমবারে utility class গুলো মনে রাখা কঠিন লাগতে পারে। তবে একবার অভ্যস্ত হলে সবকিছু সহজ হয়ে যায়।"} />

## Pre-built UI নেই

<InParagraph text={"Bootstrap-এর মতো ready-made modal, navbar, carousel ইত্যাদি Tailwind-এ নেই। নিজেই তৈরি করতে হয় (অথবা Headless UI, DaisyUI ব্যবহার করতে পারেন)।"} />

## SEO Considerations

<InParagraph text={"লম্বা class attribute যদি অনেক বেশি হয়, তাহলে HTML file size বাড়তে পারে। তবে modern bundlers এটি সমস্যা কম করে।"} />

<Tip tone={"warning"} title={"Tailwind সবসময় সেরা নাও হতে পারে"} text={"যদি আপনার দরকার হয় pre-built components, অথবা CSS class-মুক্ত HTML — তাহলে অন্য framework বেশি উপযুক্ত হতে পারে। প্রজেক্টের চাহিদা অনুযায়ী সিদ্ধান্ত নিন।"} />
