<InParagraph text={"Tailwind v4-এ `postcss` এবং `autoprefixer` আলাদা করে install করার দরকার নেই। v3-এ এগুলো প্রয়োজন।"} />

<CodeBlock code={"<head>\n  <script src=\"https://cdn.tailwindcss.com\"></script>\n</head>"} lang={"html"} title={"index.html"} />

<Tip tone={"warning"} title={"CDN Production-এ ব্যবহার করবেন না"} text={"CDN শুধু testing বা learning-এর জন্য। Production-এ npm install করে build process ব্যবহার করুন — এতে unused CSS remove হয় এবং performance ভালো থাকে।"} />

## Tailwind v3 vs v4 Install

| বৈশিষ্ট্য | Tailwind v3 | Tailwind v4 |
| --- | --- | --- |
| Packages | tailwindcss, postcss, autoprefixer | tailwindcss, @tailwindcss/cli |
| Config | tailwind.config.js | CSS-first (@theme directive) |
| Build | PostCSS plugin | CLI / Vite plugin |
| Engine | JIT | Oxide (Rust-based) |
