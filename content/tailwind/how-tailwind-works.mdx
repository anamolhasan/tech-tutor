## Build Process

1. Tailwind আপনার ফাইলগুলো (HTML, JSX, TSX ইত্যাদি) scan করে
1. কোন utility class ব্যবহার করা হয়েছে তা শনাক্ত করে
1. শুধু সেই classes-এর CSS generate করে
1. Output CSS ফাইলে শুধু প্রয়োজনীয় CSS থাকে

## JIT Engine (Just-In-Time)

<InParagraph text={"Tailwind v3 থেকে **JIT engine** default। এটি real-time সময়ে CSS generate করে, ফলে development faster এবং CSS file ছোট থাকে। Tailwind v4-এও JIT mode default, তবে এটি আরও optimized।"} />

## Output CSS

<InParagraph text={"Tailwind-এর output CSS file-এ থাকে শুধু আপনার ব্যবহৃত utility classes। যদি আপনি `bg-blue-500` ব্যবহার করেন, তাহলে output CSS-এ `bg-blue-500` class থাকবে — `bg-red-500` থাকবে না।"} />
