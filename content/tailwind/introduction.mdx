## এই অধ্যায়ে যা যা শিখবেন

- Tailwind CSS কী এবং এর পূর্ণরূপ
- Utility-First CSS কীভাবে কাজ করে
- Tailwind কেন এত জনপ্রিয়
- অন্যান্য CSS framework থেকে এর পার্থক্য

## Tailwind CSS কী?

<InParagraph text={"Tailwind CSS হলো একটি **utility-first CSS framework** যা আপনাকে low-level utility classes প্রদান করে যেগুলো সরাসরি HTML-এ ব্যবহার করা যায়। এর মানে হলো আপনাকে আলাদা CSS ফাইলে custom class লিখতে হয় না — বরং HTML-এই সরাসরি স্টাইল করতে পারেন।"} />

<CodeBlock code={"<!-- Traditional CSS: আলাদা CSS ফাইলে লিখতে হয় -->\n<button class=\"btn-primary\">Click Me</button>\n\n<!-- Tailwind: HTML-তেই সরাসরি স্টাইল করুন -->\n<button class=\"rounded-lg bg-blue-600 px-4 py-2 text-white hover:bg-blue-700\">\n  Click Me\n</button>"} lang={"html"} title={"Traditional CSS vs Tailwind"} />

## Tailwind-এর জনপ্রিয়তা

- GitHub-এ ৮০,০০০+ star (সবচেয়ে জনপ্রিয় CSS framework)
- Vercel, Netflix, GitHub, Shopify সহ বড় কোম্পানি ব্যবহার করে
- React, Vue, Angular, Svelte — সব framework-এর সাথে কাজ করে
- Next.js, Nuxt.js, SvelteKit — সব meta-framework-এ built-in support

## Tailwind CSS এক নজরে

| বৈশিষ্ট্য | বিবরণ |
| --- | --- |
| Utility-first | ছোট ছোট utility class দিয়ে স্টাইল করুন |
| Responsive | Mobile-first breakpoint সিস্টেম |
| Customizable | কনফিগ ফাইল দিয়ে সম্পূর্ণ কাস্টমাইজেশন |
| Zero runtime | Build সময়ে CSS তৈরি হয়, runtime কোনো overhead নেই |
| Dark mode | Built-in dark mode support |
