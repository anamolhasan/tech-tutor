## Official Plugins

| Plugin | কাজ |
| --- | --- |
| @tailwindcss/typography | Prose content styling |
| @tailwindcss/forms | Form element styling |
| @tailwindcss/container-queries | Container queries |
| @tailwindcss/line-clamp | Text truncation |

## Plugin Install

<CodeBlock code={"# v4: CSS-এ import\nnpm install @tailwindcss/typography\n\n# Terminal"} lang={"bash"} title={"Terminal"} />

<CodeBlock code={"@import \"tailwindcss\";\n@plugin \"@tailwindcss/typography\";"} lang={"css"} title={"src/index.css (v4)"} />

## Third-party Plugins

- **DaisyUI** — 50+ pre-built components
- **Headless UI** — unstyled, accessible components
- **tailwindcss-animate** — animation utilities
- **tailwind-merge** — merge Tailwind classes programmatically
