## Class Naming Pattern

<InParagraph text={"Tailwind class-গুলো সাধারণত এই pattern অনুসরণ করে:"} />

<CodeBlock code={"prefix:property-name\n\nউদাহরণ:\nbg-blue-500     → background color: blue, shade 500\ntext-lg         → font-size: large\np-4             → padding: 1rem (16px)\nrounded-lg      → border-radius: large\nshadow-md       → box-shadow: medium"} lang={"text"} />

## Utility Categories

| ক্যাটাগরি | উদাহরণ | কাজ |
| --- | --- | --- |
| Spacing | p-4, m-2, gap-4 | Padding, margin, gap |
| Colors | bg-blue-500, text-red-600 | Background, text color |
| Typography | text-lg, font-bold | Font size, weight |
| Layout | flex, grid, block | Display, layout |
| Sizing | w-full, h-8 | Width, height |
| Border | rounded-lg, border | Border radius, border |
| Shadow | shadow-md | Box shadow |

## Class কীভাবে পড়বেন
