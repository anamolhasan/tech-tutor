## তুলনামূলক ছক

| বৈশিষ্ট্য | Traditional CSS | Tailwind CSS |
| --- | --- | --- |
| Approach | Component/class-based | Utility-first |
| CSS file | আলাদা `.css` ফাইল লিখতে হয় | HTML-তেই utility class |
| File size | সব CSS থাকে | শুধু ব্যবহৃত CSS |
| Responsive | Media query লিখতে হয় | Prefix দিয়ে responsive |
| Dark mode | Manual media query | `dark:` prefix |
| Learning curve | CSS জানা লাগে | Utility class শিখতে হয় |
| Consistency | নির্ভর করে developer-এর উপর | Built-in scale |

## Traditional CSS-এর সুবিধা

- CSS-এর মৌলিক ধারণা ভালোভাবে শেখায়
- যেকোনো framework-এ ব্যবহার করা যায়
- Runtime overhead নেই

## Tailwind-এর সুবিধা

- দ্রুত development speed
- Built-in responsive design
- Dark mode support
- Design consistency
- Unused CSS elimination

<Tip tone={"info"} title={"পরামর্শ"} text={"Tailwind শেখার আগে মৌলিক CSS (box model, flexbox, grid, positioning) জানা ভালো। এতে Tailwind utility classes বোঝা ও ব্যবহার করা সহজ হবে।"} />
