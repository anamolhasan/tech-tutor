<InParagraph text={"**HTML**-এর পূর্ণরূপ **HyperText Markup Language**।"} />

<InParagraph text={"ওয়েবপেজের structure (গঠন) তৈরি করার জন্য HTML ব্যবহার করা হয়। এটি একটি *markup language* — অর্থাৎ এখানে কোড লেখা হয় না, বরং বিভিন্ন content-কে `ট্যাগ` দিয়ে চিহ্নিত করে গঠন দেওয়া হয়।"} />

## HyperText বলতে কী বোঝায়?

<InParagraph text={"**HyperText** মানে হলো *লিংকযুক্ত টেক্সট*। HTML-এর একটি পেজ থেকে আরেকটি পেজে যাওয়ার জন্য লিংক (`<a>` ট্যাগ) ব্যবহার করা হয় — একে Hyperlink বলে। এই Hyperlink-এর কারণেই ওয়েব জুড়ে সহজে ঘোরা যায় (browsing)।"} />

## Markup Language বলতে কী বোঝায়?

<InParagraph text={"**Markup** হলো content-এর চারপাশে ট্যাগ ব্যবহার করা, যাতে ব্রাউজার বুঝতে পারে কোন অংশ শিরোনাম, কোন অংশ প্যারাগ্রাফ, কোন অংশ ছবি ইত্যাদি। অর্থাৎ HTML content-কে *নির্দেশনা* দেয়, কীভাবে উপস্থাপন করতে হবে।"} />

## HTML কেন শিখব?

- প্রতিটি ওয়েবপেজের ভিত্তি HTML
- ইংরেজি ছাড়াও বাংলা সহ যেকোনো ভাষার content-কে সঠিকভাবে দেখাতে সাহায্য করে
- বুঝতে সহজ — শুরুতেই দ্রুত ফলাফল দেখা যায়
- CSS ও JavaScript-এর ভিত্তি প্রতিষ্ঠা করে
