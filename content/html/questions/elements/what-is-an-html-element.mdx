---

<InParagraph text={"একটি **HTML element** হলো HTML-এর মৌলিক বিল্ডিং ব্লক — এটি opening tag, কনটেন্ট এবং closing tag নিয়ে গঠিত। ব্রাউজার একটি element পড়েই বুঝতে পারে কোন অংশটি কীভাবে দেখাতে হবে।"} />

<InParagraph text={"উদাহরণস্বরূপ, `<p>`Hello`</p>` একটি paragraph element — এখানে `<p>` হলো opening tag, `Hello` হলো কনটেন্ট, আর `</p>` হলো closing tag। element-টির ভেতর optional attribute-ও থাকতে পারে।"} />
