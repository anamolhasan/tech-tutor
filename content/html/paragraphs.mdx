## লাইন ব্রেক ও হরাইজন্টাল লাইন

- `<br>` — একই প্যারাগ্রাফের ভেতরে নতুন লাইনে যাওয়ার জন্য
- `<hr>` — বিষয়বস্তুর মাঝে অনুভূমিক রেখা টানার জন্য

<CodeBlock code={"<p>প্রথম লাইন<br />দ্বিতীয় লাইন</p>\n<hr />\n<p>রেখার পরের অংশ</p>"} lang={"html"} />

## টেক্সট ফরম্যাটিং ট্যাগ

| ট্যাগ | কাজ |
| --- | --- |
| \<strong> | গুরুত্বপূর্ণ (bold) |
| \<em> | জোর দেওয়া (italic) |
| \<mark> | হাইলাইট করা |
| \<small> | ছোট টেক্সট |
| \<del> | কাটা টেক্সট |
| \<ins> | ঢোকানো টেক্সট |
| \<sub> | নিচে লেখা (subscript) |
| \<sup> | উপরে লেখা (superscript) |
