## প্রয়োজনীয় অ্যাট্রিবিউট

- `href` — `<a>` লিংকের গন্তব্য URL
- `src` — `<img>`-এর ছবির অবস্থান
- `alt` — `<img>`-এর বিকল্প টেক্সট
- `class` — CSS স্টাইল করার জন্য
- `id` — পেজের মধ্যে একটি এলিমেন্টকে অনন্য নাম দেওয়ার জন্য
- `width` / `height` — ছবির মাপ

### class বনাম id

| class | id |
| --- | --- |
| একাধিক এলিমেন্টে ব্যবহার করা যায় | একটি পেজে প্রতিটি id হয় অনন্য |
| CSS ও JavaScript উভয়েই ব্যবহৃত | লিংক ও JavaScript-এর জন্য ব্যবহৃত |
| `.` দিয়ে বোঝানো হয় | `#` দিয়ে বোঝানো হয় |
