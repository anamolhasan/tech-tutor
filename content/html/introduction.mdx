## এই অধ্যায়ে যা যা শিখবেন

- HTML কী এবং কেন এটি প্রয়োজন
- ব্রাউজার কীভাবে HTML রেন্ডার করে
- প্রথম HTML ডকুমেন্ট তৈরি করা
- HTML ডকুমেন্টের সাধারণ গঠন

## ওয়েবপেজ কীভাবে কাজ করে

## প্রথম HTML ডকুমেন্ট

<InParagraph text={"চলুন অতি সহজ একটি HTML ডকুমেন্ট দেখি। এটি একটি নোটপ্যাড বা VS Code-এ লিখে `index.html` নামে সেভ করলেই ব্রাউজারে খুলে দেখা যাবে।"} />

<CodeBlock code={"<!DOCTYPE html>\n<html lang=\"bn\">\n  <head>\n    <meta charset=\"UTF-8\" />\n    <title>আমার প্রথম পেজ</title>\n  </head>\n  <body>\n    <h1>হ্যালো বিশ্ব!</h1>\n    <p>এটি আমার প্রথম HTML পেজ।</p>\n  </body>\n</html>"} lang={"html"} title={"index.html"} />

<Tip tone={"info"} title={"মজার তথ্য"} text={"`<!DOCTYPE html>` অংশটি ব্রাউজারকে বলে যে এটি একটি আধুনিক HTML5 ডকুমেন্ট। এটি ছাড়া ব্রাউজার পুরোনো (quirks) মোডে চলে, যা বিভিন্ন রেন্ডারিং সমস্যা তৈরি করতে পারে।"} />

## HTML ডকুমেন্টের গঠন

- `<!DOCTYPE html>` — ডকুমেন্ট টাইপ ঘোষণা
- `<html>` — পুরো ডকুমেন্টের মূল কনটেইনার
- `<head>` — মেটা তথ্য, টাইটেল ও লিংক (দেখানো হয় না)
- `<body>` — স্ক্রিনে যা দেখানো হয় তার সবকিছু
