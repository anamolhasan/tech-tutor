## ছোট ও অর্থপূর্ণ commit

- এক commit = এক logical কাজ
- একসাথে ১০০ ফাইল বদলে না
- যত শীঘ্র commit, তত ভালো
- complete, runable state-এ commit করুন

## branch-এ নিয়ম মানুন

- feature branch-এ কাজ করুন
- মূল থেকে বেশিদিনে বিচ্ছিন্ন নয় — প্রায়ই rebase/pull
- PR ছোট রাখুন
- প্রথমে local-এ পরীক্ষা, তারপর push

## সতর্ক কিছু নিয়ম

- `git add -A` অন্ধভাবে নয় — `git status` আগে
- `--force` নয়; `--force-with-lease` প্রয়োজনে
- public history কখনো rewrite নয়
- রাত্রি জেগে নয় — ব্যবসায়িক কাজ commit করুন
