<CodeBlock code={"import { Stack } from \"expo-router\";\n\nexport default function RootLayout() {\n  return (\n    <Stack>\n      <Stack.Screen name=\"index\" options={{ title: \"টুডে\" }} />\n      <Stack.Screen name=\"task/[id]\" options={{ title: \"Task Detail\" }} />\n    </Stack>\n  );\n}"} lang={"tsx"} title={"app/_layout.tsx"} />

- `name` — route file-এর নাম (folder সহ)
- `options` — header title, headerShown, animation ইত্যাদি
