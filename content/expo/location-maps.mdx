<CodeBlock code={"import * as Location from \"expo-location\";\n\nasync function getCurrentPlace() {\n  const { status } = await Location.requestForegroundPermissionsAsync();\n  if (status !== \"granted\") return null;\n  const pos = await Location.getCurrentPositionAsync({});\n  const coord = { lat: pos.coords.latitude, lng: pos.coords.longitude };\n  const places = await Location.reverseGeocodeAsync(coord);\n  return places[0]?.city ?? places[0]?.name ?? \"নিজের স্থান\";\n}"} lang={"ts"} />

- foreground permission এই সেটআপেই app config-এ auto-add হয়
- background location — বিশেষ permission, সাবধানে
- `reverseGeocodeAsync` — lat/lng → city/name

<Tip tone={"info"} title={"map-এর API key"} text={"expo-go-এ react-native-maps gratis চলে; standalone build-এ (Android/iOS) নিজের Google Maps API key দরকার — `app.config`-এ দিন।"} />
