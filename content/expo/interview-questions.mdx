1. Expo ও bare React Native-র পার্থক্য? — Expo SDK + toolchain; প্রয়োজন হলে prebuild
1. React Native-এ `View` আর web-এর `div`-এর সম্পর্ক? — দুইটি container; crossorigin rendering
1. Flexbox-এর default direction? — column (react native; web-এ row)
1. AsyncStorage ও SecureStore-এর পার্থক্য? — plain key-value vs encrypted
1. FlatList কেন? — virtualization, memory efficiency
1. Expo Router কী? — file-based routing, `app/` folder
1. `useColorScheme` কী দেয়? — system theme; dark/light adaptation
1. OTA update কীভাবে কাজ করে? — eas update; runtime version match-এ download
1. Splash কখন hide হয়? — প্রয়োজনীয় asset লোড শেষে
1. EAS Build কী করে? — cloud binary build; profiles
