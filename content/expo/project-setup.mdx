<InParagraph text={"`npx expo start` চালালে console-এ QR code আসে। ফোনের **Expo Go** দিয়ে QR scan করলেই অ্যাপ ফোনে লোড হয়। `w` চাপলে web, `a` চাপলে Android emulator।"} />

### কোন template বেছে নেব

- **default** — Expo Router + TypeScript আগে থেকেই সাজানো
- **blank** — minimal, নিজে সব গোছান
- **blank-typescript** — TypeScript সহ minimal

<InParagraph text={"আমরা **default template** ব্যবহার করব — Expo Router, TypeScript, tab navigation প্রস্তুত। প্রজেক্টের নাম: **TaskTrack — একটি daily task tracker app**।"} />

<Tip tone={"info"} title={"প্রথমবার"} text={"প্রথম `npx expo start`-এ SDK-র package ডাউনলোড হয় — একটু সময় লাগে। ইন্টারনেট চালু রাখুন।"} />
