<InParagraph text={"**Expo** হলো React Native-এর **সরকারি framework** — যা দিয়ে একটি কোডবেস থেকেই iOS, Android এবং Web-এর জন্য native mobile app বানানো যায়। Camera, notifications, updates, build — কঠিন মনে হওয়া native বিষয়গুলো এক জায়গা থেকেই manage করা যায়।"} />

## কেন Expo শেখবেন

- সেটআপ মিনিট — ২ মিনিটে `create-expo-app` দিয়ে boilerplate, আর Expo Go দিয়ে ফোনেই অ্যাপ চলে
- Managed workflow — `app.json` / `app.config` ফাইলে native সেটিংসের নিয়ন্ত্রণ
- বড় SDK ecosystem — `expo-*` প্যাকেজে camera, location, notifications, SQLite ইত্যাদি ready
- OTA update — স্টোর রিভিউয়ের অপেক্ষা ছাড়াই অ্যাপ আপডেট
- Web support — একই কোড দিয়ে web build-ও সম্ভব

## এই course-এ যা শিখবেন
