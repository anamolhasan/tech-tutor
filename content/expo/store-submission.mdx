## iOS (App Store Connect + TestFlight)

- App record — Bundle ID `com.example.tasktrack`
- Screenshot 6.7-inch / 6.9-inch, icon 1024px
- Privacy policy + store listing
- TestFlight invite → review

## Android (Play Console)

- App + package name
- Keystore — EAS auto-manage (backup জরুরি)
- Android bundle (`.aab`) upload
- Content rating, data safety

<CodeBlock code={"npx eas submit --platform android\nnpx eas submit --platform ios"} lang={"bash"} title={"terminal"} />
