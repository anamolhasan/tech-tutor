- TypeScript strict — types ছাড়া mobile code বড় হলে কষ্ট
- component ছোট — এক screen এক ফাইল
- state minimal — local → context → store (যা দরকার)
- accessibility — `accessibilityLabel`, `testID`
- list + memo — FlatList performance
- theme কেন্দ্রীয় — screen-এ hardcode নয়

- version bump + changelog
- icon/splash resolution ঠিক আছে
- crash-free test — TestFlight / internal track
- error logging (Sentry) active
- credentials back-up
