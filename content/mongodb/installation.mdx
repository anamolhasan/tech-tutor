## প্রথম connection

<CodeBlock code={"import mongoose from \"mongoose\";\n\nconst MONGODB_URI = \"mongodb://127.0.0.1:27017/myapp\";\n\nexport async function connectDB() {\n  try {\n    await mongoose.connect(MONGODB_URI);\n    console.log(\"MongoDB connected\");\n  } catch (err) {\n    console.error(\"Connection failed:\", err.message);\n    process.exit(1);\n  }\n}\n\nconnectDB();"} lang={"js"} title={"db.js — ESM style"} />

<CodeBlock code={"const mongoose = require(\"mongoose\");\n\nmongoose\n  .connect(\"mongodb://127.0.0.1:27017/myapp\")\n  .then(() => console.log(\"MongoDB connected\"))\n  .catch((err) => console.error(\"Connection failed:\", err.message));"} lang={"js"} title={"db.js — CommonJS style"} />

<Tip tone={"info"} title={"127.0.0.1 কেন?"} text={"`localhost` ব্যবহার করলে কিছু সিস্টেমে IPv6-এ resolve হওয়ায় connection fail হতে পারে। `127.0.0.1` সর্বত্র কাজ করে। Atlas connection string-এ `mongodb+srv://` prefix থাকে।"} />
