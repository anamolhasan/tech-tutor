## ৩. N+1 এড়ান

- লুপে `find()` → বদলে `parallel`/`Promise.all` বা এক query-তে `$in`
- Reference-গুলো populate একবারে
- `select()` দিয়ে অযথা field-না
- Page-wise `limit/skip` — limitless নয়

## ৪. Naming নিয়ম

| নিয়ম | উদাহরণ |
| --- | --- |
| Model name — Singular, PascalCase | `User`, `BlogPost` |
| Collection — plural (default) | `users`, `blogposts` |
| Field — camelCase | `firstName`, `createdAt` |
| Schema কনভেনশন | `timestamps: true` |

## ৫. Security

- `.env`-এ secrets — `NEXT_PUBLIC_` দিয়ে client-এ পাঠাবেন না
- `findByIdAndUpdate`-এ `runValidators: true`
- Query injection ঠেকাতে input validate করুন — user-controlled raw query object-কে সরাসরি filter হিসেবে ব্যবহার করবেন না
- Password/email-এ **index + bcrypt hash**
- API limit-এ `$lookup`/aggregation-সহ complex query-র ট্র্যাক

## ৬. Mongoose + TypeScript
