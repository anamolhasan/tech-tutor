## Update

<CodeBlock code={"// field-গুলো পরিবর্তন\nawait Post.updateOne(\n  { _id: postId },\n  { $set: { title: \"নতুন টাইটেল\", views: 0 } }\n);\n\n// update করে ফেরত সেই document — { new: true }\nconst updated = await Post.findByIdAndUpdate(\n  postId,\n  { $inc: { views: 1 } },\n  { new: true }\n);\n\n// পাওয়া document-টিই update করবে\nawait Post.findOneAndUpdate(\n  { slug: \"mongoose-vs-driver\" },\n  { $set: { published: true } }\n);"} lang={"js"} title={"Update"} />

## Delete

<CodeBlock code={"await Post.deleteOne({ _id: postId });      // একটি মেলে মুছে দেয়\nawait Post.deleteMany({ published: false }); // একাধিক\nawait Post.findByIdAndDelete(postId);        // find + delete"} lang={"js"} title={"Delete"} />

<Tip tone={"warning"} title={"deleteMany() সব document"} text={"`deleteMany({})` কল দিলে collection-এর প্রতিটি document মুছে যায় — production-এ আগে `countDocuments()`/backup দিয়ে confirm করুন।"} />
