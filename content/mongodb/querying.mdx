## Chainable query

<CodeBlock code={"const popularPosts = await Post.find({ published: true })\n  .sort({ views: -1 })   // সবচেয়ে বেশি দেখা আগে\n  .limit(10)             // শুধু ১০টি\n  .skip(20)              // পেজিনেশন: আগের ২০ বাদ\n  .select(\"title views\") // শুধু দরকারি field\n  .lean();               // plain object (fast)"} lang={"js"} title={"Chained query"} />

## Comparison operators

<CodeBlock code={"// দাম ১০০ থেকে ৫০০ এর মধ্যে\nawait Product.find({\n  price: { $gte: 100, $lte: 500 },\n});\n\n// status এই কয়েকটির যেকোনো একটি\nawait Order.find({ status: { $in: [\"pending\", \"shipped\"] } });\n\n// title-এ 'mongoose' আছে এমন — case insensitive\nawait Post.find({ title: { $regex: \"mongoose\", $options: \"i\" } });\n\n// author reference-এর চেয়ে নির্দিষ্ট\nawait Post.find({ author: { $ne: someUserId } });"} lang={"js"} title={"Operator ব্যবহার"} />

| Operator | অর্থ |
| --- | --- |
| `$eq` | সমান |
| `$ne` | সমান না |
| `$gt` / `$gte` | বড় / বড় বা সমান |
| `$lt` / `$lte` | ছোট / ছোট বা সমান |
| `$in` / `$nin` | লিস্টের ভেতরে / বাইরে |
| `$regex` | Pattern match |
| `$exists` | field আছে কিনা |
