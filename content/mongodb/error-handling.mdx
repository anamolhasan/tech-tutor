## Mongoose-এর সাধারণ error

| Error | যখন ঘটে | কী করবেন |
| --- | --- | --- |
| `ValidationError` | schema validation ব্যর্থ | field-ভিত্তিক message দেখান |
| `CastError` | ভুল ObjectId/type দেওয়া | Invalid ID response দিন |
| `MongoServerError` | unique conflict (code 11000) | duplicate হিসেবে handle |
| `MongooseError (buffer)` | disconnected অবস্থায় query | connection নিশ্চিত করুন |

<CodeBlock code={"app.use((err, req, res, next) => {\n  if (err.name === \"ValidationError\") {\n    const errors = Object.fromEntries(\n      Object.entries(err.errors).map(([key, e]) => [key, e.message])\n    );\n    return res.status(400).json({ message: \"Validation failed\", errors });\n  }\n\n  res.status(err.statusCode || 500).json({\n    message: err.message || \"Internal server error\",\n  });\n});"} lang={"js"} title={"Central error handler"} />
