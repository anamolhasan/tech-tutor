<CodeBlock code={"const products = await prisma.product.findMany({\n  where: { active: true },\n  orderBy: { id: \"asc\" },\n  cursor: { id: lastSeenId },\n  take: 10,\n  skip: 1, // cursor-row পুনরায় না\n});"} lang={"ts"} />

- `orderBy` array — একাধিক column priority
- `skip` বড় offset-এ ধীর — cursor-এ বদলান
- count + findMany — total page জানতে

<Tip tone={"info"} title={"stable order"} text={"pagination-যদি data বদলায়, stable secondary (id)-সহ order দিন — না হলে offset-এ duplicate লাফিয়ে যেতে পারে।"} />
