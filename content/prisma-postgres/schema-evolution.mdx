<InParagraph text={"২-phase pattern — code-নতুন column-এ যাক, তারপর পুরোনো মুছে দাও।"} />

- নতুন column add (nullable/default)
- মিডল-টাইম — app-দুটোই লেখে
- backfill — copy/transform data
- পুরোনো column নিষিদ্ধ → drop

<CodeBlock code={"const products = await prisma.product.findMany({\n  where: { slug: null },\n  select: { id: true, name: true },\n});\n\nfor (const p of products) {\n  const slug = p.name.toLowerCase().split(\" \").join(\"-\");\n  await prisma.product.update({\n    where: { id: p.id },\n    data: { slug },\n  });\n}"} lang={"ts"} title={"backfill (prisma)"} />
