| Method | Result |
| --- | --- |
| findUnique | একটি রেকর্ড \| null (pk/unique দিয়ে) |
| findFirst | প্রথমটি \| null |
| findMany | array (কোনোটিই না হলে []) |
| count | সংখ্যা |

<Tip tone={"info"} title={"findUnique scope"} text={"`findUnique` শুধু unique/pk field-এ — অন্য field-এ হলে `findFirst`।"} />
