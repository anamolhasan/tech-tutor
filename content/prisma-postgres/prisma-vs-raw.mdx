| দিক | Raw SQL (pg) | Prisma |
| --- | --- | --- |
| Syntax | SQL string | TypeScript method |
| Type safety | নেই (নিজের হাতে) | auto-generate |
| Migration | হাতে লিখতে হয় | auto-diff |
| এক query-র জটিলতা | সব ক্ষমতা | প্রায় সব; raw fallback |
| Learning | ভিত্তি | ভিত্তি-থাকা সহজ |

<InParagraph text={"**নিয়ম**: Prisma-তে লিখুন, জটিল/অদ্বিতীয় query-এ `$queryRaw`। আর SQL ভুলে যাবেন না — Prisma-ই শেষে SQL তৈরি করে, তাই সমস্যা হলে SQL বুঝে দেখতে হয়।"} />
