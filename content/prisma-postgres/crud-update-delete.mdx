| Method | আচরণ |
| --- | --- |
| update | মিললে রেকর্ড আপডেট; না হলে P2025 |
| updateMany | matching count (0 হলেও error না) |
| delete | মিললে মুছে; না হলে P2025 |
| deleteMany | সব matching মুছে |
