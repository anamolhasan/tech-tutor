## সাধারণ event

| Event | যখন |
| --- | --- |
| `onClick` | ক্লিক |
| `onChange` | input/select/textarea-তে পরিবর্তন |
| `onSubmit` | form submit |
| `onMouseEnter` / `onMouseLeave` | hover enter/exit |
| `onFocus` / `onBlur` | ফোকাস পাওয়া/হারানো |
| `onKeyDown` | কীবোর্ড চাপা |
| `onScroll` | স্ক্রল |
