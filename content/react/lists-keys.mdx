## সঠিক key বাছুন

- **সেরা key** — ডেটাবেস-এর `id`, slug বা unique value
- **index না** — row সাজানো/filter করলে order বদলায়, state ভুল element-এ চলে যায়
- key change হলে component remount হয় (state reset হয়)
- দুটি ভিন্ন list-এ একই key থাকলে তেমন সমস্যা নেই — একই list-এর মধ্যে unique হলেই হবে

<CodeBlock code={"// index key — শেষ উপায়\n{items.map((item, index) => (\n  <Item key={index} item={item} />\n))}\n\n// ভালো — stable unique value\n{items.map((item) => (\n  <Item key={item.id} item={item} />\n))}"} lang={"jsx"} title={"Key — ভালো ও খারাপ"} />
