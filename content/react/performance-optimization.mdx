## মনে রাখা টিপস

- list-এ stable unique key দিন — index নয়
- গভীর ও ব্যয়বহুল re-render → React.memo/Compiler
- useEffect-এ ভুল dependency → infinite loop, সাবধান
- বড় bundle ও part lazy-load করুন — dynamic import
- DevTools Profiler দিয়ে আসল সমস্যা খুঁজে নিন
