## Update নিয়ম

- সরাসরি `count = 5` লিখা **হয় না** — সবসময় setter ব্যবহার করুন
- Setter-এর নতুন value পুরনো value replace করে, merge হয় না
- এক event-এ একাধিক update হলে `setCount((prev) => prev + 1)` functional update দরকার
- State change ⇒ **re-render** ⇒ UI আপডেট

<CodeBlock code={"function Counter() {\n  const [count, setCount] = useState(0);\n\n  // এক event-এ ৩ বার +১\n  const addThree = () => {\n    setCount((prev) => prev + 1);\n    setCount((prev) => prev + 1);\n    setCount((prev) => prev + 1);\n  };\n\n  return (\n    <button onClick={addThree}>+3 (count: {count})</button>\n  );\n}"} lang={"jsx"} title={"Functional update"} />
