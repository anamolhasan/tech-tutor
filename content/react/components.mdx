## Component মূলনীতি

- Component নাম **Capitalize** হতে হয়
- Props function বা element-ও হতে পারে
- Props change হলে component re-render হয়
- Child-এর ডেটা বদলাতে চাইলে parent-এ callbacks পাঠান — **lifting state**
