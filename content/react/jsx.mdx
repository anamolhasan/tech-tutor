## JSX নিয়ম

- প্রতিটি component একটি parent element return করে — `div`, `<>` (fragment) বা component
- Attribute নাম **camelCase** — `className`, `onClick`, `htmlFor`
- সব tag **self-close** — `<img />`, `<br />`
- JSX-এ `class` লেখা যায় না — `className`
- `style` object আকারে — `style={{ color: "red" }}`

<CodeBlock code={"function Badge() {\n  return (\n    <span\n      className=\"badge\"\n      style={{ backgroundColor: \"#22c55e\", padding: \"4px 8px\" }}\n    >\n      Active\n    </span>\n  );\n}"} lang={"jsx"} title={"Style ও className"} />
