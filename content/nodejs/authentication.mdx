## JWT কী?

<InParagraph text={"**JWT** হলো একটি token যা server user-কে দেয় login সময়। পরবর্তী request-এ user এই token পাঠায় এবং server verify করে। Token তিনটি অংশে থাকে: Header, Payload, Signature।"} />

## User Registration

<CodeBlock code={"const express = require(\"express\");\nconst bcrypt = require(\"bcryptjs\");\nconst jwt = require(\"jsonwebtoken\");\nconst router = express.Router();\n\nconst users = [];\nconst JWT_SECRET = process.env.JWT_SECRET || \"secret-key\";\n\n// Register\nrouter.post(\"/register\", async (req, res) => {\n  const { name, email, password } = req.body;\n\n  // check existing\n  if (users.find(u => u.email === email)) {\n    return res.status(400).json({ error: \"Email ইতিমধ্যে আছে\" });\n  }\n\n  // hash password\n  const hashedPassword = await bcrypt.hash(password, 10);\n\n  const user = {\n    id: Date.now(),\n    name,\n    email,\n    password: hashedPassword,\n  };\n  users.push(user);\n\n  res.status(201).json({ message: \"Registration successful\" });\n});"} lang={"javascript"} title={"routes/auth.js"} />

## User Login & JWT

<CodeBlock code={"// Login\nrouter.post(\"/login\", async (req, res) => {\n  const { email, password } = req.body;\n\n  const user = users.find(u => u.email === email);\n  if (!user) {\n    return res.status(401).json({ error: \"Invalid credentials\" });\n  }\n\n  const isMatch = await bcrypt.compare(password, user.password);\n  if (!isMatch) {\n    return res.status(401).json({ error: \"Invalid credentials\" });\n  }\n\n  // JWT token তৈরি\n  const token = jwt.sign(\n    { id: user.id, email: user.email },\n    JWT_SECRET,\n    { expiresIn: \"1h\" }\n  );\n\n  res.json({ token, user: { id: user.id, name: user.name } });\n});"} lang={"javascript"} />

## Auth Middleware

<CodeBlock code={"// middleware/auth.js\nconst authenticate = (req, res, next) => {\n  const token = req.headers.authorization?.split(\" \")[1];\n\n  if (!token) {\n    return res.status(401).json({ error: \"Token নেই\" });\n  }\n\n  try {\n    const decoded = jwt.verify(token, JWT_SECRET);\n    req.user = decoded;\n    next();\n  } catch (error) {\n    res.status(401).json({ error: \"Invalid token\" });\n  }\n};\n\n// protected route\nrouter.get(\"/profile\", authenticate, (req, res) => {\n  res.json({ user: req.user });\n});"} lang={"javascript"} />
