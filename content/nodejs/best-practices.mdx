## Error Handling

<CodeBlock code={"// Custom error class\nclass AppError extends Error {\n  constructor(message, statusCode) {\n    super(message);\n    this.statusCode = statusCode;\n    this.isOperational = true;\n  }\n}\n\n// Global error handler\napp.use((err, req, res, next) => {\n  const status = err.statusCode || 500;\n  const message = err.isOperational\n    ? err.message\n    : \"Internal Server Error\";\n\n  res.status(status).json({\n    status: \"error\",\n    message,\n    ...(process.env.NODE_ENV === \"development\" && {\n      stack: err.stack,\n    }),\n  });\n});"} lang={"javascript"} />

## Security

- **Helmet** — Security headers সেট করে
- **CORS** — Cross-origin request control
- **Rate Limiting** — DDoS protection
- **Input Validation** — User input sanitize করুন
- **SQL Injection** — Parameterized queries ব্যবহার করুন
- **Environment Variables** — Secrets কোডে hardcode করবেন না
- **HTTPS** — Production-এ সবসময় HTTPS ব্যবহার করুন

## Performance

- **Caching** — Redis/Memcached ব্যবহার করুন
- **Compression** — gzip/brotli middleware
- **Database Indexing** — Query optimize করুন
- **Connection Pooling** — DB connection reuse
- **PM2 Clustering** — CPU cores ব্যবহার করুন
- **Stream** — বড় ফাইলে Stream ব্যবহার করুন
