## REST API Design

| Method | Endpoint | কাজ |
| --- | --- | --- |
| GET | /api/users | সব user আনা |
| GET | /api/users/:id | নির্দিষ্ট user আনা |
| POST | /api/users | নতুন user তৈরি |
| PUT | /api/users/:id | user update |
| DELETE | /api/users/:id | user মুছে ফেলা |

## Full CRUD API

<CodeBlock code={"const express = require(\"express\");\nconst router = express.Router();\n\nlet users = [\n  { id: 1, name: \"রহিম\", email: \"rahim@example.com\" },\n  { id: 2, name: \"করিম\", email: \"karim@example.com\" },\n];\n\n// GET /api/users\nrouter.get(\"/\", (req, res) => {\n  res.json(users);\n});\n\n// GET /api/users/:id\nrouter.get(\"/:id\", (req, res) => {\n  const user = users.find(u => u.id === parseInt(req.params.id));\n  if (!user) return res.status(404).json({ error: \"User পাওয়া যায়নি\" });\n  res.json(user);\n});\n\n// POST /api/users\nrouter.post(\"/\", (req, res) => {\n  const { name, email } = req.body;\n  if (!name || !email) {\n    return res.status(400).json({ error: \"Name ও email দরকার\" });\n  }\n  const newUser = { id: Date.now(), name, email };\n  users.push(newUser);\n  res.status(201).json(newUser);\n});\n\n// PUT /api/users/:id\nrouter.put(\"/:id\", (req, res) => {\n  const user = users.find(u => u.id === parseInt(req.params.id));\n  if (!user) return res.status(404).json({ error: \"User পাওয়া যায়নি\" });\n  Object.assign(user, req.body);\n  res.json(user);\n});\n\n// DELETE /api/users/:id\nrouter.delete(\"/:id\", (req, res) => {\n  users = users.filter(u => u.id !== parseInt(req.params.id));\n  res.json({ message: \"User মুছে ফেলা হয়েছে\" });\n});\n\nmodule.exports = router;"} lang={"javascript"} title={"routes/users.js"} />

## HTTP Status Codes

| Code | অর্থ |
| --- | --- |
| 200 | OK — সফল |
| 201 | Created — নতুন resource তৈরি হয়েছে |
| 204 | No Content — সফল কিন্তু response body নেই |
| 400 | Bad Request — client ভুল |
| 401 | Unauthorized — authentication লাগবে |
| 403 | Forbidden — permission নেই |
| 404 | Not Found — resource নেই |
| 500 | Internal Server Error — server সমস্যা |
