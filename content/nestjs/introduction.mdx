## NestJS কী?

<InParagraph text={"NestJS হলো Node.js backend framework যা **modular architecture**, **dependency injection**, আর **decorators** — এই তিনটি মূল concept-এ ভিত্তি করে গড়ে ওঠে। এর under the hood Express (ডিফল্ট) or Fastify চলে।"} />

## NestJS কেন ব্যবহার করবেন?

- **TypeScript-first** — ধরনের সাথে সম্পূর্ণ type safety
- **Modular** — আলাদা module-এ কোড ভাগ, maintainable ও scalable
- **Dependency Injection (DI)** — ক্লাস gdatetime আবার testable
- **Decorator-based** — জারগন minimal, readable code
- **Structure** — architecture-এর নির্দিষ্ট guideline, ছোট project-ও পরিষ্কার
- **Ecosystem** — Mongoose, TypeORM, GraphQL, microservices — সব integrated
- **Testing** — unit & e2e testing built-in support

## NestJS বনাম Express

| বৈশিষ্ট্য | Express | NestJS |
| --- | --- | --- |
| Structure | Unopinionated (আপনার ইচ্ছা) | Opinionated (structure fix) |
| TypeScript | Optional | First-class |
| Dependency Injection | নেই | আছে (built-in) |
| Modularity | ম্যানুয়াল | আছে (module system) |
| Shining | Simple ও lightweight | Scalable ও enterprise |
| Learning curve | Easy | মধ্যম |
| Best for | Small/medium API | Large/complex application |
