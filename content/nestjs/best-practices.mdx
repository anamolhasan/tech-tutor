## 2. DTO সর্বত্র

<CodeBlock code={"// ❌ avoid — any\ncreate(@Body() body: any) {}\n\n// ✅ DTO\n@Post()\ncreate(@Body() dto: CreateUserDto) {}\n\n// separate dto per operation\n// CreateUserDto, UpdateUserDto, LoginDto"} lang={"typescript"} />

## 3. Single Responsibility

<CodeBlock code={"// Controller → HTTP layer শুধু\n// Service → business logic\n// Repository/Model → data access\n// Module → grouping\n\n// ❌ controller-এ DB logic\n@Get()\nasync findAll(@Query() q: any) {\n  const db = await getDb();\n  return db.collection('users').find().toArray();\n}\n\n// ✅ service-এ\n@Get()\nfindAll() {\n  return this.usersService.findAll();\n}"} lang={"typescript"} />

## 4. Global Validation & Filters

<CodeBlock code={"import { ValidationPipe, Logger } from \"@nestjs/common\";\nimport { HttpAdapterHost, NestFactory } from \"@nestjs/core\";\n\nasync function bootstrap() {\n  const app = await NestFactory.create(AppModule);\n\n  app.setGlobalPrefix(\"api/v1\"); // versioning\n\n  app.useGlobalPipes(new ValidationPipe({ whitelist: true, transform: true }));\n\n  app.enableCors({ origin: process.env.FRONTEND_URL });\n\n  app.useLogger([\"error\", \"warn\", \"log\"]);\n\n  await app.listen(3000);\n}\nbootstrap();"} lang={"typescript"} title={"main.ts — production baseline"} />
