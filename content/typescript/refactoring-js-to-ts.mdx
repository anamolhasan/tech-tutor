## allowJs দিয়ে শুরু

<CodeBlock code={"{\n  \"compilerOptions\": {\n    \"allowJs\": true,\n    \"checkJs\": false,\n    \"noEmit\": true\n  }\n}"} lang={"json"} title={"tsconfig.json"} />

<InParagraph text={"`allowJs` দিলে `.js` ফাইলও compile হবে — TS-এ মিশে থাকতে পারবে। `checkJs` চালু করলে শুধু ভুল ধরা পড়বে, বাধা দেবে না।"} />

## ধাপে ধাপে রূপান্তর

1. আগে `allowJs: true` ও `checkJs: true` চালু করুন — JavaScript-এই টাইপ সমস্যা দেখুন
1. নতুন ফাইল `.ts` নামে লেখা শুরু করুন
1. একেক module-কে `.js` → `.ts` rename করুন এবং `@ts-check` চালু করুন
1. সবচেয়ে গুরুত্বপূর্ণ ফাংশন/API ফাইলগুলো আগে কভার করুন
1. `any`-গুলো ধীরে ধীরে সঠিক টাইপে বদলান
1. শেষে `noImplicitAny` চালু করুন

## সহজ রূপান্তর

<CodeBlock code={"// .js\nfunction total(items) {\n  return items.reduce((sum, item) => sum + item.price, 0);\n}\n\n// .ts\ninterface CartItem {\n  name: string;\n  price: number;\n}\n\nfunction total(items: CartItem[]): number {\n  return items.reduce((sum, item) => sum + item.price, 0);\n}"} lang={"typescript"} />
