## keyof

## Modifiers: readonly ও ?

<CodeBlock code={"type ReadonlyAll<T> = { readonly [K in keyof T]: T[K] };\n\ntype OptionalAll<T> = { [K in keyof T]?: T[K] };\n\ntype Person = { name: string; age: number };\n\ntype RO_Person = ReadonlyAll<Person>;   // readonly\ntype Opt_Person = OptionalAll<Person>;  // সব optional\n\n// '-' দিয়ে modifier সরানো হয়\ntype MyRequired<T> = { [K in keyof T]-?: T[K] };"} lang={"typescript"} />
