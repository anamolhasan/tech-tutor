## strict একসাথে কী কী চালু করে

| Flag | অর্থ |
| --- | --- |
| strictNullChecks | null/undefined আলাদা টাইপ হিসেবে গণ্য |
| noImplicitAny | implicit any-তে error |
| strictFunctionTypes | function variance কঠোর |
| noUncheckedIndexedAccess | index access-এ \| undefined |
| useUnknownInCatchVariables | catch এর error: unknown |
| exactOptionalPropertyTypes | optional-এ undefined ঠিক রাখা |

## lib ও type environment

<InParagraph text={"`lib` বলে দেয় কোন runtime-এর global type জানা দরকার — ব্রাউজার হলে `DOM`, Node হলে `ES2023`+ নাইট। Node global-এর জন্য `@types/node` দরকার।"} />
