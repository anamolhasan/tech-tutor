## Open Source কী?

<InParagraph text={"Open source — code সবাই দেখতে ও ব্যবহার করতে পারে (লাইসেন্স অনুযায়ী)। GitHub-এ প্রায় ২০০ মিলিয়ন+ repositories।"} />

## লাইসেন্স basics

| লাইসেন্স | অর্থ |
| --- | --- |
| MIT | যেকোনো ব্যবহার, attribution |
| Apache-2.0 | MIT + patent নিয়ম |
| GPL-3.0 | copyleft — derivedও GPL |
| BSD-3 | সহজ, attribution |

## ভালো community-র তথ্য

- **README** — প্রজেক্ট বোঝে
- **CONTRIBUTING.md** — কীভাবে সাহায্য করবেন
- **CODE_OF_CONDUCT** — আচরণ নিয়ম
- **LICENSE** — ব্যবহারের শর্ত
- **Issue labels** — 'good first issue'

## প্রথম contribute

<CodeBlock code={"# 1. repo-টি fork করুন\n# 2. clone করুন\ngit clone https://github.com/you/project.git\n# 3. branch + fix\ngit switch -c fix/typo\n# 4. commit + push\ngit push -u origin fix/typo\n# 5. \"New pull request\" → আপনার fork → মূল repo */\n"} lang={"bash"} />

## সঠিক first issue বাছুন

- `good first issue` label
- টাইপো, ডকুমেন্টেশন, ছোট test
- maintainer-এর সাথে আগে কথা বলুন (comment)
- ছোট ও দ্রুতমূল্য ব্যবহারিক PR

## ভালো contributor-এর গুণ

- মানুষ-friendly: comment/PR-তে সরল ও শ্রদ্ধাশীল
- প্রথমে খুঁজে দেখুন issue আছে কিনা
- ধৈর্য — review-তে সময় লাগে
- চলমান conversation-এ উত্তর দিন
