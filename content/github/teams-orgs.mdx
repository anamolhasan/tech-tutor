## Organization কী?

<InParagraph text={"Organization হলো **একাধিক repository-র ওপর নিয়ন্ত্রণের স্তর** — এর সদস্য, team, নিয়ম আলাদা থাকে। একটি কোম্পানি/প্রকল্পের GitHub পরিচয়।"} />

## ব্যক্তিগত vs Organization

| ব্যক্তিগত অ্যাকাউন্ট | Organization |
| --- | --- |
| নিজস্ব repository | শেয়ারড repository |
| নিজস্ব নিয়ন্ত্রণ | সদস্য ও team-based |
| সহজ | এন্টারপ্রাইজ নিয়ন্ত্রণ |

## Team কী?

- Team হলো organization-এর ভেতরে সদস্যদের গ্রুপ
- উদাহরণ: `frontend`, `backend`, `devops`
- Team-কে repository-তে access দেয়া যায়
- @frontend mention দিয়ে সবাইকে ডাকা যায়

## Organization settings

- Member privileges
- Default repository permissions
- Require 2FA membership
- Audit log
- Security policies
