## GitHub কী?

<InParagraph text={"GitHub-এ আপনার কম্পিউটারের Git repository-গুলো **cloud-এ** রাখা যায় (hosting)। তারপর যেকোনো জায়গা থেকে সেগুলো টেনে কাজ করা যায় এবং দলের সবার সঙ্গে ভাগ করা যায়।"} />

## কেন GitHub-এ কাজ করি?

- **Remote backup** — কম্পিউটার নষ্ট হলেও কোড থাকবে
- **Collaboration** — দলের সবাই একই প্রজেক্টে কাজ করে
- **Code review** — Pull request দিয়ে গুণগত মান রক্ষা
- **Portfolio** — নিজের কাজ বিশ্বকে দেখানো
- **Open source** — বিশ্বের যেকোনো প্রজেক্টে অবদান
- **Extra tooling** — Actions, Pages, Packages

## Git vs GitHub

| Git | GitHub |
| --- | --- |
| Version control tool | Git-based hosting platform |
| আপনার কম্পিউটারে চলে | ইন্টারনেটে চলে |
| কমান্ড লাইন | ব্রাউজার + Git একসাথে |
| history সেভ করে | হোস্ট, review, CI/CD |

## GitHub-এর প্রধান অংশগুলো

- **Repository** — প্রজেক্টের সব ফাইল ও ইতিহাস
- **Branches** — আলাদা লাইনে কাজ
- **Pull Request** — merge-ের আবেদন
- **Issues** — কাজ/বাগের তালিকা
- **Actions** — automate workflow (build, test, deploy)
- **Pages** — ফ্রি ওয়েবসাইট ও ডকুমেন্টেশন হোস্ট
- **Gists** — ছোট কোড স্নিপেট শেয়ার

## সাধারণ নমুনা

<InParagraph text={"বেশিরভাগ developer-এর দৈনিক চক্র নিচের মতো: repository-তে কাজ → branch → commit → push → PR → review → merge → deploy। GitHub এই সব ধাপ এক ছাদের নিচে নিয়ে আসে।"} />
