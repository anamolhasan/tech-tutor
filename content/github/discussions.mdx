## Discussions কী?

<InParagraph text={"Discussions হলো repository-র **কথোপকথনের জায়গা** — প্রশ্ন জিজ্ঞেস, ধারণা শেয়ার, পরিকল্পনা — issue-এর মতো কাজ track করার বাধ্যতামূলক নম্বর ছাড়া।"} />

## Discussions vs Issues

| Discussions | Issues |
| --- | --- |
| ধারণা ও প্রশ্ন | নির্দিষ্ট কাজ/বাগ |
| শ্রেণীবদ্ধ কথোপকথন | এক দায়বদ্ধ টাস্ক |
| vote/upvote | priority / milestone |
| গুরুত্বপূণ কাজ বোঝায় না | নির্দিষ্ট status |

## Discussions ব্যবহার

- কোনো feature নিয়ে মতামত
- setup/solve নিয়ে সহায়তা
- show and tell — নিজের কাজ শেয়ার
- general — সবকিছু
