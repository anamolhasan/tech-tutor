## README কেন গুরুত্বপূর্ণ?

<InParagraph text={"Repository-তে প্রথম যে জিনিস visitors দেখে তা-ই README। এটি সিদ্ধান্ত নেয় — মানুষ project ব্যবহার, contribute নাকি এড়িয়ে যাবে।"} />

## ভালো README-এর কাঠামো

- **প্রজেক্টের নাম ও একটি লাইন** — কী এটি
- **Screenshot / demo** — এক চোখে বোঝা যায়
- **Installation** — কীভাবে setup করবেন
- **Usage** — কীভাবে চলবে
- **Features** — bullets
- **Tech stack** — badge
- **Contribution** — কীভাবে সাহায্য করবেন
- **License**

## Markdown-এর মৌলিক

## দরকারি Markdown syntax

| Syntax | ফলাফল |
| --- | --- |
| # Heading | বড় শিরোনাম |
| **bold** | বোল্ড |
| [link](url) | হাইপারলিংক |
| `code` | ইনলাইন কোড |
| - item | বুলেট লিস্ট |
| > quote | উদ্ধৃতি |
| \| col \| col \| | টেবিল |
