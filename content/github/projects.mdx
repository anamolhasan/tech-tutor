## GitHub Projects কী?

<InParagraph text={"Projects হলো একটি **চাক্ষুষ board** (কিংবা table/view) — যেখানে issues ও PR-গুলো status অনুযায়ী সাজানো থাকে: To do → In progress → Done।"} />

## Project তৈরি

- repo-র Projects tab (হয় organization-এ)
- New project
- টেমপ্লেট: Board / Table / Roadmap
- Status field স্বয়ংক্রিয়

## Card বানানো

- Project-এ issue যোগ করুন (add items)
- অথবা issue page-এ project select করুন
- Status বদল — drag & drop বা status field

## Views

- **Board** — কলামে status
- **Table** — row/column স্প্রেডশিটের মতো
- **Roadmap** — timeline

## Sprint/Iteration

<InParagraph text={"Project-এ iteration field যোগ করে দল নির্দিষ্ট সময়ের কাজ (sprint) ট্র্যাক করতে পারে — আগে-class পরের।"} />

<Tip tone={"info"} title={"মনে রাখুন"} text={"Projects শুধু developer-দের নয় — ডিজাইন, মার্কেটিং, পরিকল্পনা — সব দল ব্যবহার করতে পারে। এক board-ই পুরো roadmap।"} />
