## Gist কী?

<InParagraph text={"Gist হলো GitHub-এ একটি **একক ফাইল/ছোট কোড snippet** শেয়ারের দ্রুত উপায় — general repo-র heavy setup ছাড়াই।"} />

## Gist তৈরি

- gist.github.com → লিখুন
- Filename-এ extension দিন (`utils.js`)
- Public / Secret নির্বাচন
- Create public gist

## কখন ব্যবহার করবেন

- Stack Overflow-এ সাহায্য চাওয়া
- টিমে ছোট JSON config শেয়ার
- একটা কোড ধাঁচ demo
- আন-বিলে snippets
