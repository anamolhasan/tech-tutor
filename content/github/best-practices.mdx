## Repository এ নিয়ম

- পরিষ্কার README + LICENSE
- `.gitignore` official template
- Branch protection on main
- Issue/PR templates
- Release notes প্রতিবার

## একটি প্রকল্পও না বাদ

- Personal project-গুলো pinned করুন
- গুরুত্বপূর্ণ commit/তথ্য সাজান
- কার্যকর URL/কোড quality
- Contributions এলাকা দেখায় — স্বাভাবিক রাখুন

## রুটিন workflow

| ভালো | কম ভালো |
| --- | --- |
| ছোট commits + PR | ম্যামথ commit |
| আগেই PR/review | সপ্তাহেষে একবার merge |
| CI automate | হাতে build |
| branch protection | সবাই main-এ push |
