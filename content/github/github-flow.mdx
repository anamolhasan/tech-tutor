## ৫টি ধাপ

- 1. main থেকে নতুন branch বানান: `git switch -c feature/login`
- 2. নিয়মিত commit করুন — ছোট ছোট
- 3. Push করুন ও PR খুলুন
- 4. আলোচনা + review + পরীক্ষা করুন
- 5. Merge করুন ও deploy করুন

## কোন নাম দেবেন branch-কে?

- `feature/...` — নতুন ফিচার
- `fix/...` — বাগ ফিক্স
- `chore/...` — রক্ষণাবেক্ষণ
- `docs/...` — ডকুমেন্টেশন

## Merge বাটন তিনটা

| Merge টাইপ | কী করে |
| --- | --- |
| Create a merge commit | সব commit রাখে + merge commit |
| Squash and merge | এক commit-এ গুড়িয়ে দেয় |
| Rebase and merge | linear history |

## GitHub Flow-এর সুবিধা

- সরল — শুরুতেই অভ্যস্ত হন
- main সবসময় deploy-যোগ্য
- PR = built-in review
- আলাদা release cycle লাগে না
