## GitHub Pages কী?

<InParagraph text={"GitHub Pages হলো **ফ্রি static hosting** — আপনার repository থেকে HTML/CSS/JS সাইট (এবং Jekyll docs) প্রকাশ করা যায়।"} />

## Pages চালু করা

- repo → Settings → Pages
- Source: **Deploy from a branch**
- Branch: `main` folder: `/ (root)`
- Save — কয়েক মিনিটে আপনার সাইট live

## URL

<CodeBlock code={"https://anamolhasan.github.io/\nhttps://anamolhasan.github.io/my-project/\nmy-project.github.io  (organizations/users-এই রূপ)"} lang={"text"} />

## Custom domain

- Settings → Pages → Custom domain
- DNS-এ CNAME — `www.yourdomain.com` → `youruser.github.io`
- HTTPS স্বয়ংক্রিয়ভাবে (প্রভাবে আসতে কয়েক মিনিট সময় নেয়)

## Limit সম্পর্কে জেনে রাখুন

- Static site সাইট — server code চলে না
- Site বাউন্ড: 1 GB
- প্রতি মাসে কিছু soft limit
- Public repo-তে free
