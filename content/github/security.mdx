## Dependabot

- dependency vulnerability **আলাদা রিপোর্ট**
- Security updates / version updates auto-PR
- Settings → Code security

## Secrets management

- Repository Secrets (workflow-এ `${{ secrets.X }}`)
- Environment secrets
- নিশ্চিত করুন `.env` কখনো commit নয়
- Required review অথবা environments দিয়ে gate
