## Express কী?

<InParagraph text={"Express হলো Node.js-এর **back-end framework** যা routing, middleware, template engine, request/response handling — সবকিছু অনেক সহজ করে দেয়। Express-এর উপর ভর করেই Nest.js, Sails.js-এর মতো জনপ্রিয় frameworks তৈরি হয়েছে।"} />

## Express কেন ব্যবহার করবেন?

- **সহজ Routing** — GET, POST, PUT, DELETE সহজে define করা যায়
- **Middleware** — request-এর মাঝে customizable logic চালানো যায়
- **Huge Ecosystem** — বিশ্বের সবচেয়ে ব্যবহৃত Node.js framework
- **Performance** — মিনিমাল design, দ্রুত execution
- **Flexible** — মডেল, database, template anything ব্যবহার করা যায়
- **Documentation** — অসাধারণ docs ও বিশাল community

## Express বনাম Pure Node.js

| বৈশিষ্ট্য | Plain Node.js | Express.js |
| --- | --- | --- |
| তারিখ | require('node:http') | require('express') |
| Routing | হাতে কষ্ট করে parse | সহজ app.get/post |
| Middleware | নেই | আছে, robust |
| Body parsing | readFile manually | express.json() |
| Static files | হাতে লিখতে হয় | express.static() |
| সময় | বেশি | কম |
