## 2. Response Caching

<CodeBlock code={"// static caching headers\napp.use(\n  express.static(\"public\", {\n    maxAge: \"1d\",\n    immutable: true, // content changes না\n  })\n);\n\n// API caching (private) — client-side redirect\napp.get(\"/api/me\", (req, res) => {\n  res.set(\"Cache-Control\", \"private, max-age=60\");\n  res.json({ user: req.user });\n});"} lang={"javascript"} />
