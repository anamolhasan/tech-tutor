## Port mapping (-p)

<InParagraph text={"Container-এর নিজস্ব network-এ port থাকে (যেমন nginx-এর 80)। বাইরে থেকে access পেতে host-এর port-এর সাথে map করতে হয়:"} />

<CodeBlock code={"# host:container\ndocker run -d -p 8080:80 nginx\n# এখন http://localhost:8080 -এ nginx দেখা যাবে"} lang={"bash"} title={"Port publish"} />

## Detached ও interactiv mode

| Flag | মানে |
| --- | --- |
| `-d` | background-এ চালায় (detached) |
| `-it` | interactive terminal (bash-এ ঢোঁকা) |
| `-p 8080:80` | port map |
| `-e K=V` | environment variable |
| `--name web` | নাম দেওয়া |
| `--rm` | container বন্ধ হলে auto-মুছে |

## exec দিয়ে ভেতরে দেখা

<CodeBlock code={"# চলমান container-এর ভেতরে শেল\ndocker exec -it web sh\n\n# ভেতর থেকে কমান্ড (যেমন প্রসেস দেখা)\ndocker exec web ps aux\n\n# environment variable দেখা\ndocker exec web env"} lang={"bash"} title={"Debug container"} />

<Tip tone={"warning"} title={"Container অস্থায়ী"} text={"Container-এর ভেতরের file system মূলত **ephemeral** — container মুছে গেলে ডেটা হারায়। ডেটা ধরে রাখতে পরে দেখব **volumes**।"} />
