## Dev compose — hot reload

<CodeBlock code={"services:\n  api:\n    build: .\n    command: npm run dev          # nodemon / nest start --watch\n    volumes:\n      - ./src:/app/src            # host code → container\n      - /app/node_modules         # container-এর নিজ নতুন install সংরক্ষণ\n    environment:\n      - NODE_ENV=development\n    ports:\n      - \"3000:3000\""} lang={"yaml"} title={"docker-compose.dev.yml"} />

<CodeBlock code={"docker compose -f docker-compose.dev.yml up"} lang={"bash"} title={"Run dev"} />

## Production vs dev compose

- Dev-এ bind mount + dev server; prod-এ compiled code + start
- Dev-এ সমস্ত logs (`logs -f`); prod-এ logging driver/aggregation
- Compose file আলাদা রাখুন (`compose.dev.yml`, `compose.prod.yml`)

## Debugging workflow

<CodeBlock code={"docker compose ps\ndocker compose logs -f api          # শেষ logs\ndocker compose exec api sh          # ভেতরে ঢোঁকা\ndocker exec api env                 # variables check\ndocker exec api node -e \"console.log(process.env.DATABASE_URL)\"\ndocker inspect api                  # network/port/details"} lang={"bash"} title={"Diagnose helper"} />
