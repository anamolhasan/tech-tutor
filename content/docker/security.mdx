## Least privilege

- `--privileged` flag **কখনোই** ব্যবহার করবেন না
- শুধু দরকারি capabilities দিন — `docker run --cap-drop=ALL --cap-add=NET_BIND_SERVICE`
- Host folder নিজের নামে bind mount — প্রভাব সীমিত
- Unused software image-এ না — attack surface কম

## Base image hardening

| Choice | বিবেচনা |
| --- | --- |
| `node:20-slim` | slim — কম package, maintained |
| `node:20-alpine` | ছোট, তবে musl-based — কিছু native modules আলাদা |
| `distroless` (gcr.io) | শুধু runtime — shell নেই, সবচেয়ে নিরাপদ |
| `static`/`chainguard` | zero-CVE images |

## আরও চেক

- Image tag-এ exact version (`node:20-alpine`) — `latest` নয়
- `docker history` দিয়ে image-এর পূর্বে অস্বাভাবিক কিছু আছে কিনা দেখুন
- Run process-এর `USER` নিশ্চিত — `docker top <container>`
- Registry-এ private image-এ access control
- Logs/data এনক্রিপশন — TLS (HTTPS) upstream
