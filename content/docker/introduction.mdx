## Docker কী?

<InParagraph text={"সহজ ভাষায়, Docker হলো এমন একটি tool যা আপনার application-কে একটি **package (image)**-এ বান্ডেল করে এবং সেটা থেকে **container** নামের isolated process চালায়। এটি আধুনিক DevOps ও cloud deployment-এর অপরিহার্য অংশ — React, Next.js, Node.js, database — সবকিছুই Docker দিয়ে চলানো যায়।"} />

## Docker কেন ব্যবহার করা হয়?

- **একই আচরণ সবখানে** — development, testing, production-এ ঠিক একই 'works on my machine' সমস্যা শেষ
- **Isolation** — প্রতিটি app নিজের runtime ও library নিয়ে আলাদা থাকে, অন্য app-কে প্রভাবিত করে না
- **দ্রুত ডিপ্লয়** — নতুন server-এ এক কমান্ডে app চালু
- **Version control** — image-এর version tag করে যেকোনো পুরোনো version-এ ফেরা যায়
- **Scalability** — একই image থেকে যত খুশি container চালানো যায়
- **Team workflow** — onboarding-এর সময় পুরো environment setup-এর ঝামেলা থাকে না

## Docker কীভাবে কাজ করে?

<InParagraph text={"開発者は **Dockerfile** নামের একটি file লিখে বলেন image-এ কী থাকবে। Docker সেই file থেকে **image** build করে, তারপর image থেকে **container** রান হয়। Container চালু হয় ইঙ্গিত engine-এর **isolated process** হিসেবে — নিজস্ব file system, network ও resources নিয়ে।"} />
