## Restart policy

<CodeBlock code={"services:\n  api:\n    image: my-api\n    restart: unless-stopped    # crash হলে auto-restart"} lang={"yaml"} title={"compose.yml"} />

| Policy | আচরণ |
| --- | --- |
| `no` | কিছুই না (default) |
| `always` | যেকোনো অবস্থায় restart |
| `unless-stopped` | manually stop করা ছাড়া restart |
| `on-failure:5` | কথা ঠিকেই failure-এর পর restart (max 5) |

## Resource limits

<InParagraph text={"Default JSON logger-কে stdout-এ লিখুন। Docker সেই logs collector-এ নিয়ে যায় — `docker logs`, or cloud logging service (যেমন loki, cloudwatch)।"} />

## Production checklist

- Multi-stage build + হালকা base image
- Non-root user (`USER node`)
- `NODE_ENV=production` set
- Restart policy + healthcheck
- Secrets env-তে, না image-এ
- `.dockerignore` দিয়ে image ছোট করা
- `docker compose config` দিয়ে file validate
- `docker scout` / `trivy` দিয়ে vulnerability scan

<Tip tone={"info"} title={"compose config"} text={"`docker compose config` কমান্ড file validate ও resolved output দেখায় — deploy-এর আগে চালিয়ে নিন; করে syntax/আরো অন্য ভুল ধরা পড়বে।"} />
