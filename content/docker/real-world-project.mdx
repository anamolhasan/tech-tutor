## nginx routing

<CodeBlock code={"# ফ্রন্টএন্ড\nserver {\n  listen 80;\n  server_name blog.example.com;\n\n  location / {\n    proxy_pass http://web:3000;\n    proxy_set_header Host $host;\n  }\n\n  location /api/ {\n    proxy_pass http://api:5000/;\n    proxy_set_header Host $host;\n  }\n}"} lang={"nginx"} title={"nginx.conf"} />

## Deploy steps (server)

<CodeBlock code={"# 1. project folder এ যান\ncd /opt/blog\n\n# 2. config plus registry login\ncat > .env.production <<'EOF'\nMONGODB_URI=mongodb://mongo:27017/blog\nREDIS_URL=redis://redis:6379\nJWT_SECRET=<strong-random>\nNEXT_PUBLIC_API_URL=https://blog.example.com/api\nEOF\n\n# 3. pull ও start\ndocker compose -f compose.prod.yml pull\ndocker compose -f compose.prod.yml up -d\n\n# 4. check\ndocker compose -f compose.prod.yml ps\ncurl -I https://blog.example.com"} lang={"bash"} title={"One-shot deploy"} />

## সাধারণ pitfalls

- `.env.production`-এ secret + server-এ chmod 600 করুন
- Next.js-এ `NEXT_PUBLIC_*` build-time — সবসময় build-time API URL দরকার
- HTTP API-কে HTTPS-এর ভেতর proxy করলে cookies ঠিক করতে `secure` সেট করুন
- log-এ secret যেন না যায় — logger-এ filter
