## Windows ও macOS — Docker Desktop

1. `docker.com/products/docker-desktop` থেকে **Docker Desktop** ডাউনলোড
1. Windows-এ **WSL2** ব্যাকএন্ড (সেটআপের সময় Docker নিজে আপনাকে বলবে)
1. ইনস্টলের পর Docker Desktop খুলুন এবং sign in করুন
1. Terminal-এ `docker --version` চালিয়ে verify করুন

## Linux — Docker Engine

<CodeBlock code={"docker run hello-world"} lang={"bash"} title={"hello-world"} />

<InParagraph text={"এই কমান্ডে Docker Hub থেকে tiny `hello-world` image pull করে একটি container চালায়। সফল হলে একটি বার্তা দেখবেন — 'Hello from Docker!'। এটাই আপনার প্রথম container!"} />

## প্রয়োজনীয় কমান্ড

| কমান্ড | কাজ |
| --- | --- |
| `docker --version` | Docker version দেখায় |
| `docker info` | Engine তথ্য দেখায় |
| `docker run <image>` | Image থেকে container চালায় |
| `docker ps` | চলমান container list |
| `docker ps -a` | সব (স্থগিতসহ) container list |
| `docker images` | লোকাল image list |
| `docker pull <image>` | Image ডাউনলোড |
| `docker rm <id>` | Container মুছে |
| `docker rmi <image>` | Image মুছে |
