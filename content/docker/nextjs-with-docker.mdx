## Multi-stage Dockerfile

<CodeBlock code={"# Stage 1: build\nFROM node:20-alpine AS builder\nWORKDIR /app\n\nCOPY package*.json ./\nRUN npm ci\n\nCOPY . .\nRUN npm run build\n\n# Stage 2: runtime\nFROM node:20-alpine AS runner\nWORKDIR /app\n\nENV NODE_ENV=production\n\n# standalone output file-গুলোই প্রয়োজন\nCOPY --from=builder /app/.next/standalone ./\nCOPY --from=builder /app/.next/static ./.next/static\nCOPY --from=builder /app/public ./public\n\nEXPOSE 3000\nUSER node\n\nCMD [\"node\", \"server.js\"]"} lang={"dockerfile"} title={"Dockerfile"} />

## with Docker-এর বিশেষ ভুল

- `.next` ও `node_modules`-কে `.dockerignore`-এ রাখুন
- `output: standalone` ছাড়া সব file কপি করলে image ভারী হয়
- প্রতি পরিবর্তনে cache ভাঙা আটকাতে `COPY package*.json` আলাদা ধাপে দিন
- Dev mode-এ live reload চাইলে bind mount + `npm run dev` ব্যবহার করুন
