## Tag-ID gist

- `{ type: "Product", id: p.id }` → নির্দিষ্ট item-এর cache
- `{ type: "Product", id: "LIST" }` → list-নির্দিষ্ট tag (ধরে নিলেন প্রতিটি GET list এ tag)
- `"Order"` (id ছাড়া) → array-শর্টহ্যান্ড — সব Order tag
- invalidatesTag `[LIST + type]` → list ও সব detail দুটোই invalid
