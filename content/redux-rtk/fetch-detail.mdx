## Important options

| Option | কাজ |
| --- | --- |
| `skip` | condition-এ fetch এড়িয়ে যায় (ওই arg null-able) |
| `refetchOnFocus` | window focus-এ refetch |
| `refetchOnReconnect` | নেটওয়ার্ক এলে refetch |
| `pollingInterval` | periodic refetch (ms) |
| `selectFromResult` | cache-থেকে নির্দিষ্ট অংশ pick |

<Tip tone={"warning"} title={"একই id পুনরায় fetch হয় না"} text={"মনে রাখুন — একই `id`-সহ hook একাধিক component-এ use করলে **একটাই fetch**, সবাই একই cache পায়। আর fetch শেষ হলে কোনো component unmount না করলে refetch হয় না — সেটাই cache-র সুবিধা।"} />
