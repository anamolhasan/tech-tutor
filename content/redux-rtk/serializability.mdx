## কোন মান serializable নয়

- `Date` object (→ string timestamp রাখুন)
- `Map` / `Set` (→ plain object/array)
- class instance / function
- `undefined` properties

<CodeBlock code={"// খারাপ:\nitems.map((i) => ({ ...i, addedAt: new Date() }))\n\n// ভালো:\nitems.map((i) => ({ ...i, addedAt: Date.now() }))\n// বা ISO string: new Date().toISOString()"} lang={"ts"} title={"serializable state"} />

## Ignore-যদি দরকার

<CodeBlock code={"configureStore({\n  middleware: (getDefaultMiddleware) =>\n    getDefaultMiddleware({\n      serializableCheck: {\n        // নির্দিষ্ট non-serializable path এড়িয়ে\n        ignoredActions: [\"audio/play\"],\n        ignoredPaths: [\"ui.player\"],\n      },\n    }),\n  // ...\n});"} lang={"ts"} title={"specific paths ignore"} />

<Tip tone={"warning"} title={"default-সতর্ক ignore নয়"} text={"সতর্কতা দেখলে `ignore` অপশন নয় — মূলত **state-এ string/ISO** ব্যবহার করা। serializable রেখে dispatching/DevTools/SSR সব মসৃণ।"} />
