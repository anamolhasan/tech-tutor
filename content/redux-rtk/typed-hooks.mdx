## কেন typed hooks

- `useDispatch()`-এ টাইপ না দিলে error silent হয়
- `useSelector((state) => state.cart.items)` — RootState টাইপ অনুযায়ী autocomplete
- App বড় হলে `RootState` প্রতিটি file-এ import না করে hooks-থেকে আসে

<CodeBlock code={"const dispatch = useAppDispatch();\nconst items = useAppSelector((state) => state.cart.items);\n\n<button onClick={() => dispatch(increment(product.id))}>\n  +\n</button>"} lang={"tsx"} title={"Component-এ use"} />
