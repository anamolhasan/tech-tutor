<InParagraph text={"**Redux Toolkit (RTK)** হলো Redux-এর official, battle-tested utility — যা classic Redux-এর অনেক boilerplate (constants, actions, reducers আলাদা আলাদা file) দূর করে। RTK-র দুটি প্রধান অংশ:"} />

- **`createSlice`** — Reducers + action creators একীভূত
- **`configureStore`** — store + middleware setup সহজ
- **`createAsyncThunk`** — async actions
- **`createSelector`** — memoized selectors
- **`createApi` (RTK Query)** — server data fetch/cache

## Classic vs Toolkit

| বিষয় | Classic Redux | Redux Toolkit |
| --- | --- | --- |
| Setup | types, action creators, reducers আলাদা | এক `createSlice`-এ সব |
| Immutability | হাতে spread/...Obj লেখা | `immer`-ভিত্তিক write-এ mutate করলেও new state |
| Store | `createStore` + manual middleware | `configureStore` সব default |
| Recommendation | — | Official, সর্বদা আগে RTK |

## Immer magic
