## mutation trigger কী

- `[trigger, result]` array-ভিত্তিক — trigger কল করলে request হয়
- `result.isLoading / isError / error / isSuccess / data`
- Second call same arg → **dedupe** হয়; আলাদা arg → new
- `unwrap()` → success-এ value, failure-এ throw — await-able
