## builder.query vs builder.mutation

|  | builder.query | builder.mutation |
| --- | --- | --- |
| কাজ | ডেটা পড়া (GET) | write (POST/PUT/DELETE) |
| Generated counts | loading/error/data | pending/error, আর no cache-শেয়ার |
| লাইফসাইকেল | cache-ভিত্তিক, refetch | trigger-সাথে-সাথে, onSuccess |
