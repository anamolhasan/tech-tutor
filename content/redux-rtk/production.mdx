## প্রোডাকশন checklist

- **Error tracking** — listener-এ `reportError(error)`/Sentry capture
- **Auth headers** — `credentials: 'include'`, CSRF token
- **StrictMode mounted twice** — RTK Query-হীন idempotent-তা যাচাই
- **keepUnusedDataFor** দীর্ঘ → স্মৃতি/bandwidth
- **Rehydration** SSR-এ per-request store
- **Testing** — `setupListeners`, mock RTK Query hooks (MSW)
