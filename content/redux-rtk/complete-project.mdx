## Building order

1. `types` → `use-app-*` hooks → `store.ts`
1. `cartSlice` + `cartSelectors`
1. `ordersService`/`productsService` (createApi)
1. listener.ts + store-এ middleware
1. react-redux Provider wrapping
1. UI components → RTK Query হুক + slice dispatch
