## কেন client component

<InParagraph text={"React context-ভিত্তিক `Provider` client-only। তাই ReduxProvider-এ `\"use client\"` দরকার। Next.js App Router-এ এটি root layout-এ একবার mount করলেই পুরো app-এ store accessible। **Server Components** store-এর ভেতরে পড়তে পারে না (তারা context-হীন)।"} />

## Server-এ store

<CodeBlock code={"// Server Component-তে:\n// store সরাসরি নয় — API-র result নিজে প্রস্তুত fetch করে passing\n// সার্ভারে প্রস্তুত data → client component-এ initial state"} lang={"tsx"} title={"SSR-নির্দিষ্ট data (অ্যাল্টারনেট)"} />

<Tip tone={"warning"} title={"একই store instance ব্যবহারের নিয়ম"} text={"**module-level singleton store** সাধারণ client app-এ ঠিকঠাক কাজ করে। কিন্তু SSR-এ প্রতি request-এ **আলাদা store** দরকার — নাহলে এক request-এর data আরেক user দেখতে পারে। একটি `makeStore()` factory রাখুন এবং SSR-এ তা দিয়ে store তৈরি করুন। ছোট project-এ সরল singleton যথেষ্ট।"} />
