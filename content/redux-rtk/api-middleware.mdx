## মিডলওয়্যার-টা কী করে

- প্রতিটি query hook mount/unmount-এ **fetched** track করে
- cache policy অনুসারে refetch/dispatch
- Query trigger-এ ভিন্ন পরিস্থিতি (same key dedupe)
- DevTools-এ query state ও mutations দেখায়

<Tip tone={"info"} title={"মিডলওয়্যার না-ঘেরা হলে"} text={"মিডলওয়্যার না-ঘেরা থাকলে hooks compile হয় বটে, কিন্তু runtime-এ কিছু চলে না — DevTools-এ শুধু pending state দেখাবে। alignment: reducer+middleware একসাথে store-এ বসান।"} />
