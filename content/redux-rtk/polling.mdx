## pollingInterval মান

- `pollingInterval = 5000` → প্রতি ৫ সেকেন্ডে refetch
- `0` / ছাড়াই → polling বন্ধ
- component unmount → polling বন্ধ (no cleanup)
- background-refetch → UI-র উপর কোনো প্রভাব ছাড়া data updated

<Tip tone={"warning"} title={"প্রতি-splash যতটা অদ্ভুত"} text={"Polling server-এ প্রতিটি consumer-এর জন্য request বাড়ায়। অনেক consumer + ছোট interval → server-এ কম্প্রেশন। Better design — WebSocket/SSE (real-time)। Polling শুধু ছোট, justified case-এ ব্যবহার করুন।"} />
