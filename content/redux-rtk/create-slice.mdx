<CodeBlock code={"import { createSlice } from \"@reduxjs/toolkit\";\n\n\ninterface CartState {\n  items: CartItem[];      // [{ productId, qty }]\n}\n\nconst initialState: CartState = {\n  items: [],\n};\n\nconst cartSlice = createSlice({\n  name: \"cart\",\n  initialState,\n  reducers: {\n    addItem: (state, action: PayloadAction<CartItem>) => {\n      // Immer: mutate করলেও আসল state বদলায় না\n      const existing = state.items.find(\n        (i) => i.productId === action.payload.productId,\n      );\n      if (existing) {\n        existing.qty += action.payload.qty;\n      } else {\n        state.items.push(action.payload);\n      }\n    },\n  },\n});\n\nexport const { addItem } = cartSlice.actions;\nexport default cartSlice.reducer;"} lang={"ts"} title={"src/features/cart/cartSlice.ts"} />

## createSlice কী তৈরি করে

- প্রতিটি reducer-এর জন্য **action creator** (`addItem` ফাংশন)
- Action type string (`cart/addItem`) — collision এড়াতে name-prefixed
- **Reducer** — যা store-এ মাউন্ট করা যায়
