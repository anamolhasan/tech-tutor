## Store/slice

- সব Redux code TypeScript — `PayloadAction<T>`, typed hooks
- এক slice এক দায়িত্ব; `createSlice` সবসময়
- derived-value selector via `createSelector`, duplicate-state নয়
- serializable — ISO strings, plain objects

## RTK Query

- endpoints-এ `<Result, Arg>` টাইপ সবসময়
- tagTypes + provides/invalidates design-page প্রথমে
- query arg stable (primitive or memoized object)
- `refetchOnFocus` + tailored `keepUnusedDataFor`
- mutation `unwrap()` + try/catch

## UI

- সব loading/error/empty state রাখুন
- optimistic only reversible scenarios
- listener-এ side-effect (toast, refetch, analytics)
