## আরও ৩টি সূক্ষ্ম

- `selector`-এ অপ্রয়োজনীয় কাজ এড়াতে — `createSelector` শুধু input বদলে recompute করে
- জটিল state-এ `isFetching` বনাম `isLoading`-এর পার্থক্য ভুলে যাওয়া
- query arg object memo — প্রতিবার render-এ new object arg → নতুন fetch। useRef/ useMemo
