## map, filter, find

<CodeBlock code={"const prices = [100, 250, 300, 150];\n\nconst withVat = prices.map(p => p * 1.15);\n\nconst onSale = prices.filter(p => p < 250);\n\nconst found = prices.find(p => p === 300);\n\nconsole.log(withVat); // [115, 287.5, 345, 172.5]\nconsole.log(onSale);  // [100, 150]\nconsole.log(found);   // 300"} lang={"javascript"} />

| মেথড | কাজ |
| --- | --- |
| map() | নতুন array বানায় (রূপান্তর) |
| filter() | শর্ত মেনে বেছে নেয় |
| find() | প্রথম মিলে যাওয়া মান |
| reduce() | সব মান মিলিয়ে এক ফলাফল |
| includes() | আছে কি না — true/false |
