## কী কী সম্ভব JavaScript দিয়ে

- পেজের content HTML/CSS বদলানো
- ফর্ম যাচাই ও ডেটা প্রসেসিং
- API থেকে ডেটা আনা ও দেখানো
- অ্যানিমেশন ও খেলার মতো অভিজ্ঞতা তৈরি
- সার্ভারে (Node.js) অ্যাপ বানানো

## JavaScript বনাম Java

<InParagraph text={"নাম মিললেও Java ও JavaScript সম্পূর্ণ আলাদা দুটি ভাষা। Java ক্লাস-ভিত্তিক compiled ভাষা, আর JavaScript dynamic interpreted ভাষা। এরা একে অপরের সাথে সম্পর্কহীন।"} />

## JS-এর প্রকৃতি

| বৈশিষ্ট্য | ব্যাখ্যা |
| --- | --- |
| Dynamic | টাইপ runtime-এ ঠিক হয় |
| Interpreted | কম্পাইল ছাড়াই ব্রাউজারে চলে |
| Event-driven | ইভেন্টে (ক্লিক, টাইপ) সাড়া দেয় |
| Multi-paradigm | OOP, functional, procedural যেকোনো |
