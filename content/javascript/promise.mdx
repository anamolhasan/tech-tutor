## Promise-এর অবস্থা

- `pending` — চলছে
- `fulfilled` (resolved) — সফল
- `rejected` — ব্যর্থ

## Promise বানানো

<CodeBlock code={"const getResult = new Promise((resolve, reject) => {\n  const success = true;\n\n  setTimeout(() => {\n    if (success) {\n      resolve(\"সফল ডেটা\");\n    } else {\n      reject(\"ভুল হয়েছে\");\n    }\n  }, 1000);\n});\n\ngetResult\n  .then((data) => console.log(\"মিলেছে:\", data))\n  .catch((error) => console.error(\"সমস্যা:\", error))\n  .finally(() => console.log(\"শেষ হলো\"));"} lang={"javascript"} />

## then, catch, finally

<CodeBlock code={"fetchSomething()\n  .then(response => response.json())\n  .then(data => console.log(data))\n  .catch(error => console.warn(error));"} lang={"javascript"} />

## Promise.all ও Promise.allSettled

<CodeBlock code={"const userPromise = loadUser();\nconst postsPromise = loadPosts();\n\n// সব সম্পন্ন হলে\nPromise.all([userPromise, postsPromise])\n  .then(([user, posts]) => {\n    console.log(user, posts);\n  });\n\n// প্রতিটির ফল আলাদাভাবে (ব্যর্থ হলেও)\nPromise.allSettled([userPromise, postsPromise])\n  .then((results) => console.log(results));"} lang={"javascript"} />
