## Mobile-first পদ্ধতি

<InParagraph text={"সবচেয়ে ছোট স্ক্রিনের স্টাইল প্রথমে লিখি, তারপর `min-width` দিয়ে বড় স্ক্রিনের জন্য ঠিক করি। এতে ভিত্তি সহজ ও পরিচ্ছন্ন থাকে।"} />

## Fluid ইউনিট

| ইউনিট | কাজ |
| --- | --- |
| % | প্যারেন্টের % |
| vw / vh | ভিউপোর্টের প্রস্থ/উচ্চতা |
| rem | রুট ফন্ট সাইজের গুণিতক |
| clamp() | নূন্যতম থেকে সর্বোচ্চ মান |

<CodeBlock code={".hero-title {\n  font-size: clamp(1.5rem, 4vw, 3rem);\n}"} lang={"css"} />

## Responsive লেআউট

<CodeBlock code={".container {\n  max-width: 1200px;\n  margin-inline: auto;\n  padding-inline: 1rem;\n}\n\n.dashboard {\n  display: grid;\n  grid-template-columns: 1fr;\n}\n\n@media (min-width: 900px) {\n  .dashboard {\n    grid-template-columns: 260px 1fr;\n  }\n}"} lang={"css"} />
