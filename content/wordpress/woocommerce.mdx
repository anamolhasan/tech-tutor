## WooCommerce কী?

<InParagraph text={"**WooCommerce** হলো WordPress-এর সবচেয়ে জনপ্রিয় **e-commerce plugin**। এটি WordPress site-কে সম্পূর্ণ **online store**-এ পরিণত করে — product manage, cart, checkout, payment, order সবকিছু।"} />

<CodeBlock code={"Products  →  Cart  →  Checkout  →  Payment  →  Order\n   ↑\nInventory, Shipping, Tax, Coupon, Customer account"} lang={"text"} title={"WooCommerce একটি complete store management"} />

## কী কী feature পাবেন

- **Products** — simple, variable, downloadable, virtual
- **Cart & Checkout** — built-in workflow
- **Payment gateway** — bKash, Nagad, SSLCommerz (Bangladesh-এ জনপ্রিয়), Stripe, PayPal
- **Shipping** — zoned shipping cost
- **Tax** — VAT/sales tax config
- **Orders & Reports** — order manage + dashboard
- **Customer account** — registration, order history

## WooCommerce-এ কী কী লাগে

- WordPress install (self-hosted)
- একটি Theme (e-commerce-friendly)
- WooCommerce plugin
- Payment gateway account
- Courier/shipping partner (ঐচ্ছিক)
