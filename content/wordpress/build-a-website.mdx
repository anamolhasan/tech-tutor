## সম্পূর্ণ প্রক্রিয়া overview

<InParagraph text={"WordPress দিয়ে একটি complete website বানাতে এই ধাপগুলো পার করতে হবে:"} />

<CodeBlock code={"Plan → Domain → Hosting → Install WordPress → Theme\n→ Pages/Posts → Menu → Plugin → SEO → Launch"} lang={"text"} title={"পূর্ণ workflow"} />

## ধাপ ১ — Plan করুন

- Site-এর উদ্দেশ্য ঠিক করুন (blog/business/portfolio/store)
- একটি নাম ও tagline
- Hit pages list করুন (Home, About, Services, Contact…)
- রঙ/ব্র্যান্ড-এর থিম নির্বাচন করুন

## ধাপ ২ — Domain ও Hosting

<InParagraph text={"Domain registrar থেকে domain কিনুন, আর hosting কিনে nameserver/WP installer (Softaculous) সেট করুন। Hosting purchase-এর সময় SSL certificate auto-enable রাখুন।"} />

## ধাপ ৩ — WordPress install

- Hosting-এ এক-ক্লিক installer (Softaculous) ব্যবহার
- Site title, admin username/password, email ঠিক
- ইনস্টল শেষে Dashboard-এ login

<CodeBlock code={"Site Title:   My Business\nTagline:     Quality Service\nAdmin User:  admin_name (তবে 'admin' নয়)\nAdmin Email: you@email.com"} lang={"text"} title={"WordPress site elements"} />

## ধাপ ৪ — Theme install & customize

<InParagraph text={"Appearance → Themes → Add New থেকে জনপ্রিয় theme (Astra, GeneratePress, Hello Elementor) install ও activate। তারপর **Customize**-এ brand colors, logo, homepage layout সাজান।"} />

## ধাপ ৫ — Content তৈরি

<InParagraph text={"প্রয়োজনীয় **Pages** (Home, About, Services, Blog, Contact) আর কয়েকটি **Post** লিখুন। Media Library-তে ছবি আপলোড করুন।"} />

## ধাপ ৬ — Menu ও Widget

<InParagraph text={"Appearance → Menus-এ primary menu (Home, About, Blog, Contact) তৈরি করুন। Sidebar/footer-এ widget সাজান।"} />

## ধাপ ৭ — দরকারি Plugin instal

- **Contact form** — WPForms / Contact Form 7
- **SEO** — Rank Math / Yoast
- **Security** — Wordfence / Limit Login Attempts
- **Backup** — UpdraftPlus
- **Performance** — WP Super Cache / LiteSpeed Cache

## ধাপ ৮ — Setting & Launch

<InParagraph text={"Settings → Permalinks-এ **Post name** structure করুন (মান SEO-friendly)। শেষে পুরো site ব্রাউজ-এ test করে **launch** ঘোষণা করুন।"} />

<Tip tone={"success"} title={"শিক্ষার্থী train"} text={"প্রথমে আপনার computer-এ **Local** (localwp.com) দিয়ে install করে practice করুন — তারপর live-এ move। ভুল করতে ভয় পাবেন না।"} />
