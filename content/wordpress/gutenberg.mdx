## Gutenberg / Block Editor কী?

<InParagraph text={"**Gutenberg** হলো WordPress-এর আধুনিক **editor** (Block Editor নামেও পরিচিত)। এটি content-কে আলাদা আলাদা **block** হিসেবে গেঁথে তোলে। একেকটা block — Paragraph, Heading, Image, Button, Video, Column, ইত্যাদি।"} />

## Block কী?

<InParagraph text={"**Block** হলো content-এর **একটি করে ইউনিট**। Gutenberg-এ প্রতিটি অংশ আলাদা block; আপনি সেই block ধরে drag-and-drop করতে পারেন, ক্রম বদলাতে পারেন এবং প্রতিটি block আলাদাভাবে style করতে পারেন।"} />

## সাধারণ block-গুলো

| Block | ব্যবহার |
| --- | --- |
| Paragraph | সাধারণ টেক্সট |
| Heading | শিরোনাম (H2, H3...) |
| Image / Gallery | ছবি ও গ্যালারি |
| List | বুলেট/নম্বর list |
| Quote | উদ্ধৃতি |
| Button | ক্লিক-যোগ্য button |
| Columns / Group | Layout তৈরি |
| Embed | YouTube, Twitter-এর মতো embed |

<Tip tone={"success"} title={"Better than old editor"} text={"পুরোনো Classic Editor-এ শুধু টেক্সট edit করা যেত। Gutenberg-এ **Page-টির whole layout** — text, image, column সবকিছুই — সরাসরি edit করা যায়, আলাদা page builder লাগে না।"} />
