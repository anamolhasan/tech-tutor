## Page Builder কী?

<InParagraph text={"**Page Builder** হলো এমন একটি tool যা দিয়ে **coding ছাড়াই** full page design করা যায় — drag-and-drop করে। এটি কোডিং জানা না থাকলেও professional-looking layout বানায়। জনপ্রিয় page builders: **Elementor, Beaver Builder, Divi Builder**।"} />

## কীভাবে কাজ করে

<InParagraph text={"Page builder-এ page-টিকে **row, column, widget/element**-এ ভাগ করা যায়। ডানে drag করে element (text, button, form, image) এনে কাস্টমাইজ করতে হয়।"} />

<CodeBlock code={"ELEMENTOR Page\n├── Section (full-width)\n│    └── Column 1/2/3\n│         ├── Heading\n│         ├── Image\n│         └── Button\n└── Section\n     └── Testimonial slider\n          └── Star rating"} lang={"text"} title={"Elementor বলে page build-এর landscape"} />

## Elementor কী?

<InParagraph text={"**Elementor** হলো WordPress-এর সবচেয়ে জনপ্রিয় **page builder plugin** (৬০ লাখ+ active install)। এটিতে **free version**-এও অনেক widget পাওয়া যায়; pro-version-এ আরও advanced widget ও theme builder থাকে।"} />

- **Live editing** — পেজের সামনেই (frontend) edit দেখা যায়
- **Responsive** — mobile/tablet-ও আলাদা দেখে customize করা যায়
- **Widget library** — ১০০+ widget
- **Theme Builder** — pro-এ header/footer edit করা যায়

## Block Editor নাকি Elementor?

| বৈশিষ্ট্য | Gutenberg Block Editor | Elementor |
| --- | --- | --- |
| প্রকৃতি | Built-in editor | Plugin (page builder) |
| Layout control | মধ্যম | অনেক বেশি |
| Performance | হালকা | ভারী হতে পারে |
| শেখার সময় | কম | বেশি |
| কখন ব্যবহার | সাধারণ content | Design-heavy landing page |

<Tip tone={"info"} title={"মনে রাখবেন"} text={"Page builder website-কে heavy করে তুলতে পারে। অনেক বড় landing page-এর জন্য ব্যবহার করুন, কিন্তু প্রতিটা page-এ না — জানলে Gutenberg অনেক মামলা solved করে দেয়।"} />
