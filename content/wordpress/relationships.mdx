## Theme + Plugin + Content + Database

- **Theme** পেজ-এর look ঠিক করে, কিন্তু content নিজে রাখে না
- **Plugin** ফিচার যোগ করে, কিন্তু design-এর নিয়ন্ত্রণ নেয় না
- **Post/Page** হলো content — database-এ সংরক্ষিত
- **Database** title, body, settings, user, comment সব ধরে
- **Core** সবাইকে একসাথে coordinated পরিচালনা করে

## Real-world Analogy

<InParagraph text={"WordPress site-কে একটি **restaurant** কলে বলা যেতে পারে:"} />

| WordPress Component | Restaurant Analogy |
| --- | --- |
| Core (PHP) | রান্নাঘরের rule ও kitchen management |
| Theme | দোকানের সাজসজ্জা ও look |
| Plugin | অতিরিক্ত service (ডেলিভারি, booking) |
| Post/Page | মেনুতে থাকা dish |
| Database | রেসিপি/shore inventory বই |
