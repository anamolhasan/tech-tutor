## Page কী?

<InParagraph text={"**Page** হলো **static content** — যার কোনো date নেই এবং যত দরকার বদলায় না। যেমন: **About, Contact, Home, Services** — এগুলো Page। User-দের সাধারণত menu থেকে এগুলোতে যাওয়া হয়।"} />

## Page বনাম Post

| বৈশিষ্ট্য | Page | Post |
| --- | --- | --- |
| প্রকৃতি | Static | Dynamic/time-based |
| Date | নেই | Publish date থাকে |
| Order | ম্যানুয়াল (menu-এ সাজান) | Newest প্রথমে |
| Category/Tag | হয় না | হয় |
| উদাহরণ | About, Contact, Services | Blog posts, News |
| URL | /about | /?p=12 |

## Page Template

<InParagraph text={"Theme-প্রতি page-এর জন্য আলাদা **template** থাকে — যেমন full-width template, landing page template। Theme-এ সাধারণত built-in templates দেওয়া থাকে, আর page builder দিয়ে প্রতিটি page-কে নিজের মতো design করা যায়।"} />

<Tip tone={"success"} title={"সহজ নিয়ম"} text={"সাময়িক/নিয়মিত আপডেটের content → **Post**; স্থায়ী, menu-ভিত্তিক content → **Page**। এতেই পুরো website structure clear হয়ে যায়।"} />
