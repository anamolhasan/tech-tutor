## WordPress.com কী?

<InParagraph text={"**WordPress.com** হলো একটি **hosted service** — অর্থাৎ WordPress team নিজেই hosting, domain, security, backup সবকিছু manage করে। আপনি শুধু account বানিয়ে blog/website শুরু করতে পারবেন। এটি ব্যবহার শুরু করা সবচেয়ে সহজ, তবে customization-এর সীমাবদ্ধতা আছে।"} />

## WordPress.org কী?

<InParagraph text={"**WordPress.org** হলো আসল **self-hosted WordPress software** — এটি আপনি বিনামূল্যে ডাউনলোড করে নিজের server/hosting-এ install করেন। এখানে **পূর্ণ স্বাধীনতা** — সব Theme, সব Plugin, সম্পূর্ণ code control আপনার হাতে।"} />

<CodeBlock code={"1. Domain name (e.g. mysite.com)\n2. Hosting (কোথাও WordPress install করবেন)\n3. WordPress.org থেকে WordPress download\n4. নিজের server-এ install ও configure"} lang={"text"} title={"WordPress.org-এ যা দরকার"} />

## মূল পার্থক্য এক নজরে

| বৈশিষ্ট্য | WordPress.com | WordPress.org |
| --- | --- | --- |
| Hosting | Company দেয় | নিজে manage করতে হয় |
| খরচ | Free plan + paid plan | Hosting খরচ নিজের |
| Themes | সীমিত, কিছু paid | হাজারো, সব free |
| Plugins | শুধু paid plan-এ | সব Plugin install যায় |
| Code access | নেই | সম্পূর্ণ access |
| Ads | Free plan-এ WordPress ads | নিজের site, নিজের নিয়ম |
| কন্ট্রোল | কম | সম্পূর্ণ |

## কোনটি বেছে নেবেন?

- **শখের blog বা সহজ শুরু** → WordPress.com sufficient
- **Professional website / business / e-commerce** → WordPress.org best
- **Theme ও Plugin নিয়ে পরীক্ষা করতে চান** → WordPress.org
- **পুরো code control চান** → WordPress.org
