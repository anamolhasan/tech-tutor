<InParagraph text={"**WordPress** হলো বিশ্বের সবচেয়ে জনপ্রিয় **CMS (Content Management System)**। ইন্টারনেটের প্রায় **40%-এর বেশি website** WordPress দিয়ে তৈরি — ছোট blog থেকে শুরু করে বড় e-commerce store, news portal, university website সবকিছুই।"} />

## WordPress কী?

<InParagraph text={"সহজ ভাষায় WordPress হলো এমন একটি **platform** যেখানে coding না জেনেও আপনি সামগ্রী (content) তৈরি, edit ও manage করতে পারেন। এটি মূলত **PHP** language-এ লেখা এবং **MySQL** database ব্যবহার করে। ওয়েবপেজ দেখাতে লাগে **HTML, CSS ও JavaScript** — সেগুলোর জটিলতা WordPress নিজেই সামলায়।"} />

<CodeBlock code={"WordPress (PHP + MySQL)\n   ↓\nHTML + CSS + JavaScript  →  ব্রাউজারে সুন্দর website"} lang={"text"} title={"WordPress কীভাবে তৈরি হয়"} />

## CMS কী?

<InParagraph text={"**CMS**-এর পূর্ণরূপ **Content Management System**। এটি এমন একটি software যার মাধ্যমে content (লেখা, ছবি, ভিডিও) তৈরি, edit, publish ও organize করা যায়। দরকার নেই কোনো developer-এর — আপনি নিজেই content-কে control করবেন।"} />

- **Content Management** — লেখা/ছবি যোগ-বিয়োগ করা
- **User Management** — কে কী করতে পারবে তা নির্ধারণ
- **Design Management** — Theme বদলালেই নতুন look
- **Extension** — Plugin যোগ করে নতুন functionality

## WordPress কেন CMS?

<InParagraph text={"WordPress শুরু হয়েছিল ২০০৩ সালে blog platform হিসেবে। আজ এটি প্রতিটি ধরণের website-এর জন্য ব্যবহৃত হয়। এর এত জনপ্রিয়তার কারণগুলো:"} />

- **বিনামূল্যে (Open Source)** — WordPress নিজে সম্পূর্ণ ফ্রি
- **কোনো কোডিং দরকার নেই** — সবকিছু Dashboard থেকে manage
- **Themes** — এক ক্লিকে website-এর design বদলানো
- **Plugins** — দরকারি feature যোগ করা (contact form, SEO, payment)
- **SEO-friendly** — search engine-এ ভালো rank-এ আসে
- **বিশাল Community** — ৬০,০০০+ Plugin, হাজারো Theme, countless tutorials
- **Customizable** — নিড হলে developer দিয়ে সম্পূর্ণ custom code-ও লেখানো যায়

## WordPress দিয়ে কী তৈরি করা যায়?

<InParagraph text={"WordPress-এর কোনো নির্দিষ্ট সীমা নেই — নিচের প্রায় সব ধরণের website-ই এটি দিয়ে বানানো যায়:"} />

| Website-এর ধরণ | ব্যাখ্যা | উদাহরণ |
| --- | --- | --- |
| Blog | নিয়মিত লেখা প্রকাশের জন্য আদর্শ — WordPress-এর মূল ক্ষেত্র | ব্যক্তিগত blog, magazine |
| Portfolio | নিজের কাজ/প্রজেক্ট দেখানোর graceful layout | Designer, photographer-এর site |
| Business website | Company-র পরিচিতি, service, contact | Small business site |
| News website | খবর খুব দ্রুত publish করার system | News portal, magazine |
| E-commerce | WooCommerce-এর মাধ্যমে product বিক্রি | Online shop, e-commerce store |
| Documentation website | সহজে খুঁজে পড়া যায় এমন structure | Product docs, knowledge base |
| Membership website | Specific user-দের জন্য exclusive content | Paid course site, community |
| LMS (Learning Management System) | অনলাইনে course তৈরি, enroll ও quiz | Online school, coaching |

<Tip tone={"info"} title={"মজার তথ্য"} text={"WordPress-এর দুটি রূপ আছে — **WordPress.com** (hosted service) ও **WordPress.org** (self-hosted software)। এই কোর্সের ভেতরে দুটোর পার্থক্য বিস্তারিত দেখা হবে।"} />
