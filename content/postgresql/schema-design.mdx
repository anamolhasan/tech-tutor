<InParagraph text={"ভালো schema-র লক্ষ্য: **duplication নেই, data সঠিক, query সুবিধাজনক**। ডিজাইনের সময় ৩টি প্রশ্ন: কী কী entity, প্রতিটির কী কী attribute, আর একটার সাথে অন্যটার relation কী।"} />

- **Normalization** — একটি fact এক জায়গায়; duplicate না রাখা
- Entity → table, attribute → column
- প্রতিটি table-এ stable **primary key**
- Relation — foreign key দিয়ে
- Test query লিখে দেখুন — schema এর আগে-থেকে query"-able
