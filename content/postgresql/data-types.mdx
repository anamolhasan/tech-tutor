| Type | কখন | উদাহরণ |
| --- | --- | --- |
| text / varchar(n) | text অংশ; varchar-এ length limit | name |
| integer / bigint | সব small/medium number | qty |
| numeric(p, s) | money/যথার্থতা ওয়ালা decimal | price |
| boolean | true/false | in_stock |
| timestamp / timestamptz | moment | created_at |
| date | শুধু দিন | birth_date |
| uuid | globally unique id | order_id |
| jsonb | structure-less data | product_spec |
