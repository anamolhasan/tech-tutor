<CodeBlock code={"BEGIN;\n\nUPDATE products SET qty = qty - 2 WHERE id = 1;\nINSERT INTO order_items (order_id, product_id, qty, price)\nVALUES (100, 1, 2, 24000);\n\nCOMMIT;\n-- কোনো ভুল হলে: ROLLBACK;"} lang={"sql"} title={"order fulfill — সব-or-নথিং"} />

| ACID | অর্থ |
| --- | --- |
| Atomicity | সব সফল নতুবা কিছুই হয় না |
| Consistency | constraints সবসময় ঠিক থাকে |
| Isolation | concurrent transaction-এ আলাদা দেখায় |
| Durability | commit-এর পর data হারায় না |

- `psql`-এ প্রতিটি statement নিজে auto-commit হয় — transaction-থাকতে `BEGIN` দিলেই group
- Error হলে transaction aborted — `ROLLBACK` বা `SAVEPOINT`
- Isolation level — READ COMMITTED (default) থেকে SERIALIZABLE

<CodeBlock code={"BEGIN;\nINSERT INTO products (name, price) VALUES ('A', 10);\nSAVEPOINT after_a;\nINSERT INTO products (name, price) VALUES ('B', 20);\n-- B ভুল বুঝলাম — up to after_a ঘুরে যাই\nROLLBACK TO SAVEPOINT after_a;\nCOMMIT;"} lang={"sql"} title={"savepoint"} />

<Tip tone={"warning"} title={"ইন্টারঅ্যাক্টিভ সময়"} text={"Transaction খুলে রেখে (BEGIN → query gap) রাত চলে গেলে লক জমা হয়। সার্ভার code-এ transaction block **স্বল্প-সময়** রাখুন।"} />
