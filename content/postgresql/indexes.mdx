<CodeBlock code={"CREATE INDEX idx_orders_user ON orders (user_id);\nCREATE INDEX idx_products_name ON products (name);"} lang={"sql"} />

<InParagraph text={"Index-এ থাকলে WHERE/JOIN/ORDER-এ scan-এর বদলে **lookup** — দ্রুত। তবে index **লেখা ধীর** করে (write-time-এ index update)।"} />

| Index type | কখন |
| --- | --- |
| B-tree (default) | equality, range, ORDER BY |
| GIN | array, jsonb, full-text |
| BRIN | খুব বড়, sorted-tuple data |
| Partial (WHERE সহ) | নির্দিষ্ট subset |

<CodeBlock code={"-- partial + unique\nCREATE UNIQUE INDEX uq_coupons_code_active\nON coupons (code) WHERE active;"} lang={"sql"} />
