- Column/table naming — `snake_case`, plural table-নাম
- প্রত্যেক table-এ `id` PK + `created_at`
- money-তে `numeric`, timestamp-এ `timestamptz`
- FK সবসময় index (যদি তা PK না হয়)
- সব query parameterized — injection নয়
- Big INSERT batch-এ transaction + prepared
- `SELECT *` বাদ; explicit columns
