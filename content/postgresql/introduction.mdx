## কেন PostgreSQL

- **ACID** — transactions-এ সব-or-নথিং; financial data-র জন্য জরুরি
- **JOIN** — একাধিক table-এর data relation ও aggregation native SQL
- **Extensions** — PostGIS (GIS), uuid, full-text search
- **JSONB** — relational + document দুটিই
- **Row-level security**, views, triggers, window functions
- Mature tooling — pgAdmin, Prisma, DBeaver, cloud (Neon, Supabase)

## কোন project-এ প্রযোজ্য

- Relational data — user, order, product-এর মতো সম্পর্কযুক্ত সত্তা
- Data integrity জরুরি — banking, e-commerce, inventory
- Reporting / analytics — aggregation ও CTE দিয়ে
- Web app main database — Node/Express/NestJS/Next.js-এর সাথে
