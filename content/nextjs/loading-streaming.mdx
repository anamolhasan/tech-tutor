## Suspense

<InParagraph text={"`<Suspense>` দিয়ে page-এর **নির্দিষ্ট অংশ** আলাদা ভাবে stream করা যায় — বাকিটা সাথে সাথে show হয়।"} />

<CodeBlock code={"import { Suspense } from \"react\";\nimport BlogList from \"../components/blog-list\";\nimport BlogListSkeleton from \"../components/blog-list-skeleton\";\n\nexport default function BlogPage() {\n  return (\n    <div>\n      <header>\n        <h1>Welcome to the Blog</h1>\n      </header>\n      <main>\n        <Suspense fallback={<BlogListSkeleton />}>\n          <BlogList />\n        </Suspense>\n      </main>\n    </div>\n  );\n}"} lang={"tsx"} title={"app/blog/page.tsx"} />

<InParagraph text={"এখানে header সাথে সাথে আসে, আর `BlogList`-এর data ready হলে stream হয়।"} />

## Meaningful Loading States

- **Skeleton** — ভবিষ্যৎ UI-এর আভাস, best practice
- **Spinner** — কিছু process চলছে বোঝায়
- **Priority Content** — cover photo, title ইত্যাদি আগে
