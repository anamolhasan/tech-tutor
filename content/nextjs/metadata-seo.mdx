## generateMetadata (Dynamic)

<CodeBlock code={"import type { Metadata } from \"next\";\n\nexport async function generateMetadata({\n  params,\n}: {\n  params: Promise<{ slug: string }>;\n}): Promise<Metadata> {\n  const { slug } = await params;\n  const post = await getPost(slug);\n\n  return {\n    title: post.title,\n    description: post.excerpt,\n    openGraph: {\n      title: post.title,\n      description: post.excerpt,\n    },\n  };\n}"} lang={"tsx"} title={"app/blog/[slug]/page.tsx"} />

## Common Metadata Fields

| Field | কাজ |
| --- | --- |
| title | ব্রাউজার tab ও SERP-এ শিরোনাম |
| description | SERP-এ সংক্ষিপ্ত বিবরণ |
| openGraph | Social media share preview |
| keywords | SEO keywords |
| robots | index/noindex নিয়ন্ত্রণ |
| alternates | Canonical URL |

<Tip tone={"info"} title={"Metadata Files"} text={"`sitemap.ts` ও `robots.ts` ফাইল দিয়েও automatic SEO ফাইল তৈরি হয়। আর `opengraph-image.png` দিয়ে social preview image।"} />
