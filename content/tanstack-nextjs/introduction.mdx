## ব্যবহৃত প্রযুক্তি

| টুল | ভূমিকা |
| --- | --- |
| **Next.js** (App Router) | Frontend ফ্রেমওয়ার্ক ও API route (Route Handler) |
| **TypeScript** | সম্পূর্ণ type safety |
| **Axios** | HTTP client — REST API-তে request |
| **TanStack Query** | Server state — fetch, cache, mutations |
| **TanStack Table** | Headless table — columns, sorting, actions |
| **React Hook Form** | Form state ও validation integration |
| **Zod** | Schema validation — client ও server |
| **shadcn/ui** | Dialog, Input, Select, Table-এর মতো UI components |
| **REST API** | Next.js route handlers দিয়ে products endpoints |

## এই কোর্সে যা যা শিখবেন

- Axios instance ও API client তৈরি
- TanStack Query দিয়ে data fetching ও caching
- Create / Update / Delete mutation ও cache invalidation
- Optimistic update, pagination, search, filter, sorting
- TanStack Table দিয়ে dynamic table
- React Hook Form + Zod দিয়ে validated form
- Dialog/modal ও delete confirmation
- Error handling, loading states ও reusable components
- Production architecture ও interview questions
