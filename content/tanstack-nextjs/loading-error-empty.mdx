## কোন status কখন

| State | কখন সত্য |
| --- | --- |
| `isPending` | প্রথমবার ডেটা নেই, fetch চলছে |
| `isFetching` | যেকোনো fetch চললে (background সহ) |
| `isError` | query শেষবার ভুল হয়েছে |
| `isSuccess` | data আছে |
| `isRefetching` | ডেটা আছে + আবার fetch হচ্ছে |
