## কেন Controller (Select-এ)

<InParagraph text={"shadcn `Select` শুধু `onValueChange`/`value` বোঝে — `register`-এর input-event pattern মানে না। তাই **Controller** দিয়ে RHF-কে শুনিয়ে দিচ্ছে: value + onChange. `name=\"category\"` মাধ্যমেই validation তার schema-র সাথে মিলে।"} />

## Dialog-এ ব্যবহার

<CodeBlock code={"const createProduct = useCreateProduct();\n\n<Dialog open={open} onOpenChange={setOpen}>\n  <DialogContent>\n    <DialogHeader>\n      <DialogTitle>নতুন Product</DialogTitle>\n    </DialogHeader>\n    <ProductForm\n      isSubmitting={createProduct.isPending}\n      onSubmit={(values) => {\n        createProduct.mutate(values, {\n          onSuccess: () => setOpen(false),\n        });\n      }}\n    />\n  </DialogContent>\n</Dialog>"} lang={"tsx"} title={"Create dialog"} />
