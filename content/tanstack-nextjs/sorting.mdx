## Client-side vs Server-side sorting

| বিষয় | Client-side | Server-side |
| --- | --- | --- |
| ডেটা | পুরো list client-এ | শুধু current page |
| Performance | ছোট list-এ ভালো | লাখ-লাখ row-এ ভালো |
| Set up | TanStack Table নিজেই করে | আমরা sort state manage করি |
| এই project | — নয় | ✓ (server-side) |
