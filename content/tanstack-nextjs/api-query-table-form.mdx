| স্তর | থাকে | দায়িত্ব |
| --- | --- | --- |
| **API layer** | `lib/products-api.ts` | Axios-সহ HTTP + types |
| **Server/API route** | `app/api/products/*` | ডেটাবেজ read/write |
| **Query layer** | `lib/hooks/*` | TanStack cache, mutations |
| **UI layer** | `components/products/*` | Table, Form, Dialog render |

## data flow — একটা সংক্ষিপ্ত ধাপ

1. উপরের `ProductForm` → `useCreateProduct().mutate(values)`
1. `mutationFn` → `productsApi.create(values)` → Axios POST
1. server route: validate → insert → নতুন `Product` return
1. query `onSuccess` → `invalidateQueries(productKeys.all)`
1. table-এর query refetch → নতুন `items`-সহ render

## খুঁজে বের করবেন ভুল কোথায়

- **Form জমা নেই** → zod errors দেখুন (FieldError), API-তে ভুল body
- **Table পুরনো** → invalidate হয়েছে কিনা; Devtools-এ lastUpdated দেখুন
- **Query-র ডেটা undefined** → queryKey mismatch; API ভিন্ন shape
- **loading চির** → staleTime বেশি/cache hit; network tab দেখুন
