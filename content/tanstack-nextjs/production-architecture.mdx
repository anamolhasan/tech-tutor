## SSR vs CSR ডেটা

| ডেটা | SSR (RSC) | CSR (TanStack) |
| --- | --- | --- |
| গোটা-page প্রাথমিক list | দারুণ SEO/initial paint | skeleton পরে |
| ইন্টারেক্টিভ dashboard filter/search | প্রতিটি filter-এ fetch HTML | ✓ tanstack cache+invalidate |
| user-নির্দিষ্ট ডেটা | Cookies/auth-সহ | token-সহ client fetch |

## নিরাপত্তা বিষয়

- **সার্ভার-সাইড validation** — client validation সহজ bypass হয়; সবসময় schema-সহ re-validate
- **Auth** — API route-এ session/token check
- **Rate limit** — brute force থেকে বাঁচাতে
- **environment variables** — `NEXT_PUBLIC_API_URL` শুধু public; secret `.env.local`-এ
- **id/slug** — বিশ্বাস করবেন না, validate করুন

## Deploy sort-out

- `npm run build` clean — `npx tsc --noEmit` আলাদা check script
- Envs production-এ (.env.production)
- DB migration
- অবজার্ভেবিলিটি — error tracking (Sentry)

<Tip tone={"warning"} title={"premature optimization নয়"} text={"SSR+CSR hybrid দরকার হয় যখন এটা measurable। শুরুতে plain CSR-ই ঠিক থাকবে — তারপর performance budget মাপুন, তারপর migrate। ডিফল্ট **সহজ** আর **সঠিক**।"} />
