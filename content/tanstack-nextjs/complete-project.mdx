## শুরু থেকে শেষ: ক্রম

1. `types/product.ts` — model + API shapes
1. `lib/validators/product-schema.ts` — zod
1. `lib/query-client.ts` + `lib/axios.ts` — setup
1. `lib/query-keys.ts` + `lib/hooks/*` — query layer
1. `components/products/*` — UI
1. `app/products/page.tsx` — composition

## সম্ভাব্য টুইট

- `useProducts`-এ `enabled` flag (focus/search এড়ায় আলতো fetch)
- server-side `initialData` seed (SSR)
- URL searchParams sync (shareable filters)
- row selection (bulk delete)
