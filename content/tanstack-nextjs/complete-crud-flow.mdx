## ডেটা flow সংক্ষেপ

1. User search/filter বদলায় → `search`/`category`/`status` state
1. `params` object-এর ভেতরে → `useProducts`-এর queryKey
1. TanStack Query ডেটা fetch → `ProductList` render
1. Create/Edit/Delete → mutation → invalidate → table refresh
