## Devtools-এ কী দেখা যায়

- প্রতিটি query-র **key**, state (fresh/stale/inactive), fetch count
- ডেটা কখন lastUpdated — cache hit হওয়ায় fetch skipped হয়েছে কিনা
- Query inspect → **Refetch**, **Invalidate**, **Remove** button
- Mutations tab — চলমান/সমাপ্ত mutation ও variables
- Explorer — queryKey ও data-র ভেতর দেখতে পারে
