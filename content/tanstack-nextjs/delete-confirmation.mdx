## কেন e.preventDefault

<InParagraph text={"`AlertDialogAction` ডিফল্ট dialog বন্ধ করে দেয়। আমরা চাই disabling state-এর পরে delete শেষ হয়ে `onOpenChange(false)` ডাকা হোক — তাই onClick-এ preventDefault করে সেটা নিজে manage করছি। (যদি চাই তাৎক্ষণিক close, তবে ছাড়া concern নয়।.)"} />

## dashboard-এ wiring

<CodeBlock code={"const [deletingProduct, setDeletingProduct] = useState<Product | null>(null);\nconst deleteProduct = useDeleteProduct();\n\n<DeleteDialog\n  product={deletingProduct}\n  open={deletingProduct !== null}\n  onOpenChange={(open) => {\n    if (!open && !deleteProduct.isPending) setDeletingProduct(null);\n  }}\n  isDeleting={deleteProduct.isPending}\n  onConfirm={() => {\n    deleteProduct.mutate(deletingProduct!.id, {\n      onSuccess: () => setDeletingProduct(null),\n    });\n  }}\n/>"} lang={"tsx"} title={"Page-এ"} />

<Tip tone={"success"} title={"destructive pattern"} text={"destructive action-এ সুস্পষ্ট শব্দ: 'হ্যাঁ, মুছে ফেলুন' — চোখে চলে। `AlertDialogCancel` সর্বদা keep করুন — user-কে ফাঁস বিহীন বিকল্প দিন।"} />
