(values) => {\n            updateProduct.mutate(\n              { id: editingProduct!.id, input: values },\n              { onSuccess: () => setDialogOpen(false) },\n            );\n          }\n        : (values) => {\n            createProduct.mutate(values, {\n              onSuccess: () => setDialogOpen(false),\n            });\n          }}\n    />\n  </DialogContent>\n</Dialog>"} lang={"tsx"} title={"এক Dialog-এ দুই মোড"} />

## কেন একটি Dialog

- দুই code-path মিলে যাওয়ায় duplicate কম
- `editingProduct === null` মানেই create — সুস্পষ্ট
- Dialog component loop-height একবারই mount হয়
- নতুন feature দরকার হলে (যেমন duplicate) সহজে মোড বাড়ানো যায়

<Tip tone={"warning"} title={"loading state দুই দিক"} text={"`isSubmitting` আলাদা-আলাদা mutation-এর pending — dialog একটিই, কিন্তু নিশ্চিত রাখুন: create-চলাকালীন edit dialog নিজে-নিজে খুললে যেন ভুল pending না লাগে। `editingProduct ? updateProduct.isPending : createProduct.isPending` — এমন যুক্তি ঠিক।"} />
