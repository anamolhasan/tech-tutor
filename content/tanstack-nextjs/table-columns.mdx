## প্রতিটি অংশ বুঝি

| অংশ | কাজ |
| --- | --- |
| `accessorKey` | row-এর কোন property পড়বে |
| `header` | column title (string বা component) |
| `cell` | প্রতিটি cell কীভাবে render হবে |
| `row.original` | সেই row-এর সম্পূর্ণ Product object |
| `getValue<number>()` | accessorKey-এর মান type-সহ |
