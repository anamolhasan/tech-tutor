## Confirm dialog-এ delete

<CodeBlock code={"const deleteProduct = useDeleteProduct();\n\nfunction confirmDelete() {\n  deleteProduct.mutate(product.id, {\n    onSuccess: () => {\n      setOpen(false);        // alert dialog বন্ধ\n    },\n  });\n}\n\n// alert-dialog-এর confirm button\n<Button\n  variant=\"destructive\"\n  disabled={deleteProduct.isPending}\n  onClick={confirmDelete}\n>\n  {deleteProduct.isPending ? \"মুছে ফেলা হচ্ছে…\" : \"Delete\"}\n</Button>"} lang={"tsx"} title={"Delete hook ব্যবহার"} />

## নোট: delete-এর পরে

- সব variant invalidate করলে ফিল্টার/পেজ যাই থাকুক cache সঠিক থাকে
- optimistic delete চাইলে পরের অধ্যায়ে দেখব
- DELETE-এর response-এ সাধারণত body থাকে না — `deleteProduct` returns void
