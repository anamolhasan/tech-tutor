## প্রতিটি folder-এর কাজ

- `app/products/page.tsx` — dashboard page, সবকিছু যুক্ত হয় এখানে
- `components/products/` — this domain-এর UI টুকরো
- `lib/hooks/` — TanStack Query hooks (query + mutation)
- `lib/` — Axios, API functions, query keys, schemas
- `types/` — ডেটা ও API-এর TypeScript types

<Tip tone={"info"} title={"Feature-based grouping"} text={"ছোট project-এ folder-গুলো flat (সমান স্তরের) রাখা ঠিক; বড় project-এ **feature-first** grouping (প্রতিটি feature-এর নিজস্ব components/hooks) বেশি maintainable। এই কোর্সে products feature-কে আলাদা রেখেছি — pattern-টা এভাবেই বোঝা যায়।"} />
